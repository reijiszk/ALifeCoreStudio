v1.0IEC Studio User Manual

A Browser-Based Interactive Evolutionary Computation (IEC) Tool

1What is IEC Studio?

IEC Studio is an Interactive Evolutionary Computation (IEC) tool that runs entirely in your browser. No installation needed: just double-click the file to launch it.

Ordinary evolutionary computation (GA) automatically decides good from bad with an "evaluation function", but in IEC, human preference itself is the selection pressure. When you choose the one you like from the 3×3 = 9 individuals on screen, it becomes the parent of the next generation of 9 individuals. Just by repeating this, shapes evolve toward "beauty" or "interest" that are hard to measure with a formula (Richard Dawkins's "Biomorphs" are a classic example).

The idea behind this tool Recent advances in generative AI are reshaping the "understanding by building" (constructive) style of modeling in complex systems and artificial life. By giving a prompt with just the skeleton of an idea, not a complete specification, you can auto-generate a wide variety of models, have the AI explain them when you want to understand them, and refine ideas through dialogue. Letting the AI generate everything, however, tends to produce wildly inconsistent results.
ALifeCoreStudio (the three studios, ABM / EVO / IEC) keeps a common framework for model construction, visualization, and analysis fixed and lets generative AI produce only the essential parts of a model. It is intended for beginners with no programming experience giving free form to their ideas, students growing models together with AI, and researchers building prototypes quickly. By making it easy to generate possible models freely within a shared framework, it aims to accelerate the constructive approach to scientific understanding and to spread the joy of imagining and running "what worlds could be."
How it differs from EVO Studio EVO Studio automatically selects the best via an evaluation function. IEC Studio's difference is that you yourself choose by clicking. It suits subjects with no single correct answer, decided by preference (design, shape, pattern).

What you can do: compare and select among 9 individuals to evolve them; switch between 1-parent (mutation only) and 2-parent (crossover + mutation); adjust mutation rate and mutation width with sliders; check the gene definition and the contents of the center individual; copy, save, and reproduce the genes of an individual you like; play animated individuals; save a model you built to .js and reload it; and more.

What you can't do: internet access, loading external data, 3D rendering, and the like are not supported.

3Using Built-in Models

Choose one from the "── Select a model ──" dropdown in the code bar, and the code is set automatically, showing the 9 individuals.

Branching Shapes (9 genes, static)
9 integers, as in Dawkins's Biomorphs. A branching tree evolves into insect- or plant-like shapes.
Face Evolution (static, aesthetic selection)
Choose the shape of eyes, eyebrows, nose, mouth, hair, etc. by preference. An accessible example of IEC.
Stained Glass (static, Voronoi)
Colors a Voronoi diagram that divides the plane by seed points. A visualization of spatial partitioning.
Math Art (static, z=f(x,y))
Maps a sum of sines to color. The pattern changes continuously with the coefficients.
Flock (flocking, animated)
A flock that moves via 3 rules: separation, alignment, cohesion. Evolve its movement style.
Virtual Creature (soft body, voxels)
A creature made of voxels that walks via actuator expansion/contraction (animated).
Sound Evolution (melody)
Evolve a short 8-note melody by preference, listening with "▶ Play sound".
When you want to read the code After applying a model, open ▸ Code to see the full code. 📋 Copy Spec hands a generative AI the specification plus the current code together.

4Evolution Controls

Selecting an individual

Click the one you like out of the 9 individuals. The next generation of 9 individuals is then born as small variations of that individual as parent. The center cell (★) stays the parent unchanged, so the shape you chose is always preserved as one of the nine.

1-parent mode and 2-parent mode

ModeDetails
1 parent: mutation only (default)Click one individual you like. 9 individuals are born as mutations of it as parent. Good for patiently growing in one direction.
2 parents: crossover + mutationClick two individuals in turn, as parent A and parent B. Children are born by crossing over (mixing) the genes of both. Good for combining the strengths of two individuals.

Crossover type

In 2-parent mode, choose uniform / one-point / two-point crossover via Crossover type at bottom left. Uniform picks a parent randomly for each gene; one-point and two-point split the array at cut points and inherit from each segment.

Reset

⟳ Reset in the control bar below the grid returns to a random initial set of 9 individuals. If you get stuck, you can explore from a fresh starting point.

Recording the population

The ⏺ Record button under the grid captures all nine individuals at once as a single video, with the generation number burned into the corner. Animated models (Flock, Virtual Creature) are recorded as they move, and static models are recorded as they change from generation to generation, so a selection session can be shown as one clip. Press it again to stop, and the file downloads.

The format selector next to it offers MP4 / WebM / Auto. MP4 is written as H.264, which QuickTime Player, PowerPoint, and Keynote open directly. The video is recorded at the current thumbnail size, so pick Size: Large or larger before recording if you want a higher-resolution clip.

Animation

For animated models (flock, virtual creature), Animation is shown on the right, letting you play/pause and adjust speed (0.1×-8×). ● Anim lights up in the header while it is running.

5Parameters and Genes

Operator parameters

Adjust mutation strength in "Operator parameters" on the right (applied starting from the next generation created. See ⓘ on each item for an explanation).

ParameterMeaning
Mutation rate (mutRate)Probability that each gene changes. Larger values spread the 9 individuals out more.
Mutation width (mutScale)The size (multiplier) of a single change. Smaller keeps individuals close to the parent; larger produces bolder changes.

Some models have their own parameters (e.g., Branching Shapes has # genes mutated (nMut) and mutation size (stepSize)).

Genes (definition and center individual)

Chips show the definition of the genes currently in use (the length of the numeric array and each gene's range, GENE_RANGES) as well as the genes of the center individual (★) itself. For models with a geneGrid, like the virtual creature, morphology and phase are shown clearly as a colored grid.

Gene editor

A field for saving and reproducing individuals you like.

1
Import via a cell's 📋 GenesA button that appears when you hover over a cell. Clicking it loads that individual's genes (a JSON numeric array) into the editor, and copies them at the same time. You can paste and save them in a text editor, etc.
2
↓ Place in center / ⊕ Expand to allPaste saved genes into the editor and either place them in the center individual, or expand them to all 9 individuals as parent. Lets you resume from a shape you liked before.

6Saving and Reproducing Results

In IEC, it's important to keep the "shapes you liked". There are 3 ways to save and reproduce them.

MethodUse
Copy genesCopy an individual's genes with each cell's 📋 Genes. Save it as text and later paste it into the "Gene editor" to restore it (§5).
Save/open .jsSave the model (code) with 💾 Save .js in the code bar, and load it with 📂 Open. Always save your custom models.
Copy Spec📋 Copy Spec hands the specification plus the current code to a generative AI, so you can discuss improvements.
📦 Download ZIPThe 📦 Download ZIP next to the lineage checkbox exports all data since initialization as a ZIP. For later analysis and reproduction. See below.

Lineage and branching

Show lineage under the grid lists the parent chosen in each generation, left to right. Clicking any thumbnail continues breeding from that ancestor.

The branch you were on is not discarded. It stays on screen, dimmed and labelled past, and your next selection begins a new branch from the ancestor you clicked, labelled now. Ancestors in a past branch remain clickable, so you can go back and fork again from anywhere. Up to four earlier branches are kept; beyond that the oldest is dropped. ⟳ Reset clears them all.

The ZIP export records the current branch in lineage.csv, and every preserved branch in data.json under lineageBranches.

📦 Download all data (ZIP, v1.0)

Pressing 📦 Download ZIP below the grid, next to Show lineage, exports all data since initialization into a single ZIP. It contains:

FileContents
metadata.jsonModel name, export timestamp, generation count, gene length, plus the experiment settings: parameters, selection mode (mutation only / crossover+mutation), crossover type, gene ranges, and the random seed.
model.jsThe exact model code that produced this experiment. Paste it back into the code panel and press ▶ Apply to reproduce it.
frames.jsonlAll 9 individuals at each generation (one JSON line per generation, {"tick":<gen>, "state":{"population":…, "chosen":…}}). IEC is lightweight, so this is always recorded and the bundled viewer can replay every generation.
lineage.csvGene history of the parent (center ★ individual) chosen in each generation. Columns are step, gen, g0, g1, ….
population.csvGenes of the current 9 individuals. is_center=1 marks the center (★) individual.
data.jsonStructured JSON bundling the settings, lineage, and current population. For loading from a program.

Reproducing each generation, and viewer replay

So you can reproduce each generation later, IEC always records all 9 individuals of every generation to frames.jsonl (one click = one generation of lightweight data, so there is no record on/off toggle). It also records the seed that fixes the mutation/crossover randomness.

Drop the exported ZIP onto the bundled ALifeCoreStudio_Viewer.html to replay each generation along a timeline, showing the 9 individuals in a grid rendered by the model's own drawing code (the chosen one is marked ★). It works for built-in models as well as modified or newly-created ones.

7Generating Code with AI

Pressing ✨ New Model Prompt copies a specification. Paste it into a generative AI, write the [Model to implement] section, and send it, and you'll get back code you can just paste in.

Model description spec (key points)

// Static model: 3 required functions
function createInitialGenome() { /* return an array of numbers (the individual's genes) */ }
function mutateGenome(genome, params) { /* return a new, mutated array */ }
function drawPhenotype(ctx, genome, W, H) { /* draw the genes as a picture */ }

// Animated model: ANIMATED=true plus 3 functions (in place of drawPhenotype)
const ANIMATED = true;
function initState(genome, W, H) { /* return the animation's initial state */ }
function stepState(state, dt, genome, W, H) { /* advance one frame */ }
function drawFrame(ctx, state, genome, W, H) { /* draw the current state */ }

// Optional
const GENE_RANGES = [ [min,max], ... ]; // range of each gene
const PARAM_DEFS = [ ... ];            // sliders (adding help is helpful)
function geneGrid(genome) { ... }       // show genes as a colored grid
Note Only mutateGenome in a static model receives params (the slider values). drawPhenotype / initState, etc. receive only the genes and the drawing area. The animation speed slider is shown automatically when ANIMATED=true, and dt (elapsed time × speed) is passed to stepState.
Tips for phrasing your request Be clear about "what shape or pattern" and "what genes (changeable elements)". Having the AI make small gene changes shift the appearance continuously makes comparing the 9 individuals work well. If you want it to move, add "with animation".

9Modifying Code

Pressing ✏️ Modify Prompt copies the current code together with a frame for modification instructions. Paste it into a generative AI, list what you want changed as bullet points, and the entire modified code is returned. Select all in the code field and replace it, then ▶ Apply.

Pressing 📖 Explain Prompt copies a prompt asking for an explanation of what subject the currently running code implements (requesting an overview, an explanation of the algorithm, and pseudocode). Pasting it into a generative AI gets you an explanation faithful to the implementation. Also, if you put const TITLE = 'model name' into generated or modified code, it is reflected in the browser tab name, the "About this model" heading, and the filename for 💾 Save .js (e.g. Branching_Shapes.js).

A design that makes even the free tier less likely to fail The v1.0 prompts are narrowed to a minimal specification and strongly instruct, at both the start and the end, to "output exactly one code block, in full, without omission" (to reduce output getting cut off or explanatory text mixing in, on free-tier or smaller models). ✏️ Modify Prompt places [What to change] at the end, so list your changes there as bullet points.
Tips for modifying Don't change too much at once: request 1-2 small changes at a time. It's safer to keep a state you liked via 💾 Save .js or by copying its genes.

🤖 AI Generate: connect directly to a generative AI's API (LM Studio / cloud)

Pressing 🤖 AI Generate in the code bar lets you connect directly to an OpenAI-compatible API to modify or create code. The code that comes back is automatically inserted into the code field (it is not run until you press ▶ Apply). No copy and paste needed.

  • Local (LM Studio, etc.): start a local server and turn "Enable CORS" ON in the server settings. The endpoint is http://localhost:1234 (no API key needed).
  • Cloud (OpenAI-compatible): examples are OpenRouter https://openrouter.ai/api/v1, DeepInfra https://api.deepinfra.com/v1/openai, OpenAI https://api.openai.com/v1. Requires an API key (mostly pay-as-you-go).
  • Choose the model name via 🔄 Fetch List (manual entry also works). Settings are remembered by the browser.
When the connection doesn't work "Failed to fetch" is usually caused by the server not running, CORS not enabled, or a wrong URL. Open http://localhost:1234/v1/models directly in the browser and check whether JSON is returned. For cloud services, the service itself must support CORS (OpenRouter and DeepInfra do).

Branching Shapes (Dawkins's 9 genes)

A model recreating the "Biomorphs" from Richard Dawkins's The Blind Watchmaker. The genes are 9 integers. The first 8 determine branch direction and length, and the 9th determines branching depth. Branches extend recursively, symmetric left-right from the center, drawn in black and white.

Mutation characteristics: designed, as in the original, so that "a few genes each change by ±1", adjustable via # genes mutated (nMut) and mutation size (stepSize) (the default is 2/1, so two genes shift by one step each). Over generations, the tree keeps changing into shapes resembling insects, birds, or plants.

Face Evolution

Has genes for the shape and placement of parts such as eyes, eyebrows, nose, mouth, contour, and hair, and evolves them toward a face you prefer. Being able to choose by criteria that are hard to put into words, like "cute" or "scary", makes this a quintessential IEC model. Changing the angle of the eyebrows or mouth corners changes the expression.

Stained Glass

Builds a Voronoi diagram (a partition into regions closest to each point) from multiple seed points placed on the plane, and colors each region. Genes are the positions and colors of the seed points. The spatial partition becomes the pattern itself, and moving a seed point changes the glass layout.

Math Art

Draws a pattern by mapping the value of a two-variable function z = f(x, y) (such as a sum of sines) to color. Genes are the formula's coefficients. Since the pattern changes continuously with small changes to the coefficients, this is well suited to searching for "a pattern you like" in IEC.

Flock (Flocking)

An animation of a flock moving via Reynolds's Boids (3 rules: separation, alignment, cohesion). Genes include the strength of the 3 rules, perception radii, speed, and so on. Compare and choose by the character of the movement (how it clusters or scatters) to evolve toward flock behavior you prefer. Use Animation on the right to play and adjust speed.

Virtual Creature (Soft Body, Voxels)

A soft-body creature whose body is made of 5×5 voxels (empty, rigid, soft, horizontal/vertical actuator) and which moves via the periodic expansion/contraction of actuators. Genes are morphology (each cell's type) and control (phase). Thanks to geneGrid, morphology and phase are displayed as a colored 5×5 grid. Select and evolve by how interesting the movement or body shape is (animated).

Sound Evolution

A model with genes for a short 8-note melody, which you can actually listen to via each cell's ▶ Play sound before choosing. An example of IEC where you choose by ear rather than by visual shape; click and evolve whichever melody feels pleasant or interesting.

10Errors and Solutions

If an error occurs when you press ▶ Apply, a red message appears in the code bar. The line number of the cause, that line's content, and a hint are shown. Syntax that cannot be used (class, document.*, window.*, fetch, setTimeout, import, etc.) is detected before applying.

Message / symptomWhat to do
createInitialGenome is requiredCheck that the 3 required functions (createInitialGenome / mutateGenome / drawPhenotype) are all present. For animation, initState / stepState / drawFrame replace drawPhenotype.
addEventListener cannot be usedReceive input via the sliders in PARAM_DEFS.
... is not definedA misspelled variable name, or it's used before being defined. const declarations such as GENE_RANGES can be used.
Unexpected token ...Check that parentheses () {} [] are matched, and that no comma or semicolon is missing.
The 9 individuals are blank / all look the sameCheck whether drawPhenotype is actually using the genes to draw, and whether the mutation rate is too small.

11Frequently Asked Questions

Q. The 9 individuals are too similar and I can't choose.
A. Raising Mutation rate / Mutation width on the right will spread them out more. Lower them if things change too much instead.

Q. Things change too much and I can't settle on a direction.
A. Lowering Mutation rate / Mutation width gives gentler changes closer to the parent. Growing patiently in 1-parent mode is also effective.

Q. I want to go back to a shape I liked.
A. Copy and save the individual you liked with 📋 Genes. You can later paste it into the "Gene editor" and restore it with ↓ Place in center (§5).

Q. No sliders appear.
A. If PARAM_DEFS is absent, only the default Mutation rate and Mutation width are shown. If you want a custom slider, ask a generative AI to "add PARAM_DEFS, with help text too".

Q. The animation doesn't move.
A. Animation requires const ANIMATED = true plus initState / stepState / drawFrame. Static models don't show the Animation panel.

Q. No child appears in 2-parent mode.
A. In 2-parent mode you need to click two individuals in turn. With only one clicked, it stays waiting for the second selection. Choose the crossover type at bottom left.

Q. My code disappears when I close the browser.
A. There is no auto-save. Keep a file with 💾 Save .js and load it next time with 📂 Open. It's also reassuring to copy and save the genes of individuals you liked.

📚References and Sources

These are the representative original sources the built-in subjects draw on. All code is an independent implementation by this project (for the virtual creature, the code is independently implemented, drawing on the inspiration noted below).

  • Interactive Evolutionary Computation (IEC) in general: Takagi, H. (2001). Interactive evolutionary computation: Fusion of the capabilities of EC optimization and human evaluation. Proceedings of the IEEE, 89(9), 1275–1296.
  • Branching shapes (Biomorphs): Dawkins, R. (1986). The Blind Watchmaker. Longman Scientific & Technical.
  • Interactive evolution of images: Sims, K. (1991). Artificial evolution for computer graphics. Computer Graphics (SIGGRAPH '91), 25(4), 319–328.
  • Flock (flocking / Boids): Reynolds, C. W. (1987). Flocks, herds and schools: A distributed behavioral model. Computer Graphics (SIGGRAPH '87), 21(4), 25–34.
  • Virtual creature (soft body, voxels): Bhatia, J., Jackson, H., Tian, Y., Xu, J., & Matusik, W. (2021). Evolution Gym: A large-scale benchmark for evolving soft robots. NeurIPS 2021. The idea is drawn from Evolution Gym (MIT License); the code itself is independently implemented.
  • Stained glass: a planar partition based on the Voronoi diagram.
  • Face, math art, and sound evolution: general applications of IEC, with no specific original source.
