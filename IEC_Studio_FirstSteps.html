🤔 What is IEC Studio?

IEC Studio is a browser-based tool for "Interactive Evolutionary Computation (IEC)". No installation needed: just double-click the file to use it.

Ordinary evolutionary computation (GA) measures quality with a formula (evaluation function). In IEC, that role is played by your "preference". Click the one you like out of 9 individuals in a 3×3 grid, and it becomes the parent of the next generation of 9 individuals, gradually evolving toward the shape you prefer.

All you decide is "the shape of the genes" and "how to draw a picture from the genes," and even that can be built by a generative AI and simply pasted in.

The idea behind this tool Recent advances in generative AI are reshaping the "understanding by building" (constructive) style of modeling in complex systems and artificial life. By giving a prompt with just the skeleton of an idea, not a complete specification, you can auto-generate a wide variety of models, have the AI explain them when you want to understand them, and refine ideas through dialogue. The catch is that letting the AI generate everything tends to produce wildly inconsistent results.
ALifeCoreStudio (the three studios, ABM / EVO / IEC) keeps a common framework for model construction, visualization, and analysis fixed, and lets generative AI produce only the essential parts of a model. This supports beginners with no programming experience giving free form to their ideas, students growing models together with AI, and researchers building prototypes quickly. By making it easy to generate possible models freely within a shared framework, we hope to accelerate the constructive approach to scientific understanding and spread the joy of imagining and running "what worlds could be."
All you need A browser with IEC Studio (the HTML file) open + a generative AI service (ChatGPT, Gemini, Claude, etc.; the free tier is enough)
How it differs from Evo / ABM Studio Evo runs on an evaluation function, and ABM runs on rules for individuals. IEC's defining feature is that a human chooses, with no evaluation function to write. This lets you evolve values that are hard to express as a formula, such as beauty or preference.

That's it. There's no need to read or write code. First, let's experience the feeling of "choosing makes it evolve" with the models that come built in.

▶️ First, try a built-in model

IEC Studio comes with models built in from the start. Let's try running one.

1
Choose a model

Choose a model from the dropdown in the code bar at the bottom of the screen. 9 candidates will be displayed.

2
Click the individual you like

The next generation of 9 individuals is created with the one you chose as parent. Just repeat this to evolve toward the shape you prefer. Use ⟳ Reset to start over from a random initial population.

A recommended way to explore Start by choosing "Branching Shapes", then keep clicking whatever shape you find even slightly appealing. After about 10 rounds of selecting, you'll find a "creature to your own taste" growing, looking nothing like the original. This is the experience of evolution: "a shape grows just by choosing".
Features worth knowing about
  • 1-parent / 2-parent mode: Switch between mutating a single selected individual, or selecting two individuals and crossing (interbreeding) them.
  • 🔍 Enlarge: A button that appears when you hover over a cell, showing that individual larger (animated ones keep moving). Look closely before choosing.
  • Show lineage: Lists the history of parents chosen so far. Click a thumbnail to resume breeding from that ancestor (rewind), letting you try different branches.
  • 📦 Download ZIP: the 📦 Download ZIP button next to the lineage checkbox bundles all data since initialization into a ZIP. It contains all 9 individuals of every generation frames.jsonl, the lineage of chosen parents lineage.csv, the current 9 individuals population.csv, the experiment settings (selection mode, crossover type, parameters, random seed, etc.) in metadata.json, all data in data.json, and the model code itself model.js.
    Drop the exported ZIP onto the bundled ALifeCoreStudio_Viewer.html to replay each generation's 9 individuals in a grid, rendered with the model's own drawing (the chosen one marked ★; built-in, modified, or new models all work). IEC is lightweight, so states are always recorded, with no on/off toggle needed.
  • About this model: Shown at the top of the right panel: an explanation of the genes, phenotype, and how selection works.
  • Mutation rate / mutation width: The larger these are, the more the child differs from the parent. Raise them when things stop changing much.
  • ⛶ Fullscreen: A header button that enlarges just the 9-individual grid to fill the screen. Handy for projector display or viewing together as a class.
  • 💾 HTML Export: Exports the currently running model as a single HTML file with no editing UI. Useful for saving, distributing, submitting, or presenting.

👁️ Reading the lineage, enlarged view, and overview

Let's learn three views unique to IEC that make it easier to use.

1
Show lineage (history of chosen parents)

Check the box below the grid, and the parent chosen at each generation is arranged from left to right. Click a thumbnail to resume breeding from that ancestor, letting you try and compare different branches.

2
🔍 Enlarge (observe up close)

Appears at bottom left when you hover over a cell. Shows that individual larger, and for animated models you can observe how it moves at different speeds. If you like it, select it with "Next generation from this individual".

3
About this model

At the top of the right panel is written the gene (what changes), phenotype (how it becomes a picture), and how selection works. Reading it first makes it easier to choose.

Tips for making the most of these If you're unsure, raise the mutation rate to get more varied candidates, then 🔍 Enlarge to look closely before choosing. If you get stuck, go back to an earlier ancestor via Lineage and try a different direction. This alone greatly widens your exploration.

✏️ Modify a running model (start here)

This is the easiest entry point. Just tweaking a built-in model a little can bring it closer to what you're interested in. Pressing the "✏️ Modify Prompt" button copies the current code together with modification instructions.

📖 Explain Prompt and model name When you want to know "how it works" for the subject currently running, press 📖 Explain Prompt. A request for an explanation, including the current code, is copied, so pasting it into a generative AI gets you a careful explanation with an overview, an explanation of the algorithm, and pseudocode. Also, code that is generated or modified gets a const TITLE = 'model name', which is reflected in the browser tab name, the "About this model" heading, and the filename for 💾 Save .js (e.g. Branching_Shapes.js).
1
Press "✏️ Modify Prompt"

Found in the code bar. The current code is automatically included in the prompt.

2
Paste it into a generative AI and write "what you want to change"

In the [What to change] section at the end of the pasted prompt, list what you want changed as bullet points, 1-2 items at a time.

3
Replace all the code with what comes back

Select all in the code field (Ctrl+A), paste (Ctrl+V), and press "▶ Apply".

Example modification requests by model (2 each) 💬

Base modelIdeas for modification instructions to the AI
🌿 Branching Shapes
  • Increase the max number of branches and depth to make more complex shapes.
  • Add color as a gene so each branch has a different color.
🐦 Flock (Flocking)
  • Increase the population size for a bigger flock.
  • Add one predator so the flock shows fleeing behavior.
🪟 Stained Glass
  • Increase the number of regions (Voronoi seed points) for a finer pattern.
  • Add a parameter that can bias the coloring toward cool or warm tones.
🧬 Soft-Body Creature
  • Expand the voxels to 6×6 for a more complex body.
  • Set it to underwater (high drag) so it shows a swimming-like motion.
🌀 Math Art
  • Make the pattern more likely to be left-right symmetric or rotationally symmetric.
  • Increase the number of colors used for a more colorful result.
🙂 Face Evolution
  • Add hairstyle variation as a gene.
  • Make facial expression (mouth corner, eyebrow angle) a gene so smiling or troubled faces appear.
🎵 Sound Evolution
  • Increase the number of notes from 8 to 16 for a longer melody.
  • Add rhythm (note duration) as a gene as well, so it can vary.
Tips for modifying Trying to change too much at once tends to fail. It's best to request 1-2 small changes at a time and check that it works after each one.

✨ Have a generative AI build a new model for you

Once you're used to modifying, you can also build a new model from scratch. Pressing the "✨ New Model Prompt" button copies a specification to hand to a generative AI onto the clipboard.

1
Press "✨ New Model Prompt"

Found in the code bar at the bottom of the screen. You're good once you see "Copied".

2
Paste it into a generative AI and rewrite it

Paste it into the generative AI's chat field, rewrite the [Model to implement] section to describe what you want to evolve, and send it.

3
Copy the code and paste it into IEC Studio

Copy just the contents of the code block (```javascript ... ```) that the generative AI output, paste it into the code field, and press "▶ Apply".

Phrasing your request like this gets the point across 💬

In IEC, the trick is to convey "what the genes are (what changes), and what picture is drawn from the genes". Since a human chooses what's good, no evaluation function is needed.

🙋
Example student input
I want to evolve flower shapes by "preference".
Make petal count, color, and pointiness genes, and draw 9 flowers. When clicked, show 9 similar flowers.
🙋
Example student input
I want to evolve a geometric "logo".
Make the number of shapes, rotation, and coloring into genes, so symmetric patterns tend to appear.
📋 Example request to a generative AI (what to write in the [Model to implement] section)
Please build a model that evolves the subject you want to evolve (e.g., a flower, a logo, a pattern, a creature) by "preference".

The genes (things that change bit by bit) are what (e.g., color, count, angle, size).
The way to draw a picture from the genes is what it looks like (e.g., a radial flower, a geometric pattern).

If you want a moving picture, mention that too (animation support).
Since a human clicks to choose what's good, no evaluation function is needed.

🤖 Connect directly to a generative AI API (local / cloud)

Instead of copying and pasting to a generative AI, you can also connect directly to an LLM running on your own PC (such as LM Studio) and complete modification or creation entirely within the Studio. There's no need to paste code back and forth, and the benefit of running locally is that nothing is sent over the network. Any OpenAI-compatible API can be used (LM Studio, Ollama, OpenAI, etc.).

What you need An OpenAI-compatible server such as LM Studio (free). Load one model and start the local server.
1
Start the server in LM Studio

Load a model → Start "Local Server". Turn "Enable CORS" ON in Server Settings (required to connect from the browser).

2
Press "🤖 AI Generate"

Found in the code bar at the bottom of the screen. A settings panel opens; check the endpoint (default http://localhost:1234) and the model name. You can choose the model name via 🔄 Fetch List. Settings are remembered, so you won't need to do this again next time.

3
Choose "Modify / Create New", write your instructions, and ▶ Send

Choose "✏️ Modify Existing Code" or "✨ Create New", write what you want, and send it. The generated code is automatically placed into the code field. Check the content and run it with ▶ Apply.

When the connection doesn't work "Failed to fetch" is usually caused by the server not running, CORS not enabled, or a wrong URL. First open http://localhost:1234/v1/models directly in the browser and check whether JSON is returned. If it is, LM Studio is working correctly. You can also type the model name in manually.

Using cloud generative AI services (OpenRouter, DeepInfra, OpenAI, etc.)

In addition to local servers, OpenAI-compatible cloud APIs can also be used from the same panel. There's no need to run your own server: just enter each service's base URL as the "Endpoint", the key you issued as the "API Key", and the model name.

ServiceEndpoint (Base URL)Example model names
OpenRouterhttps://openrouter.ai/api/v1openai/gpt-4o-mini, deepseek/deepseek-chat, etc.
DeepInfrahttps://api.deepinfra.com/v1/openaimeta-llama/Meta-Llama-3.1-8B-Instruct, etc.
OpenAIhttps://api.openai.com/v1gpt-4o-mini, etc.
Notes on using cloud services These require an API key, and most are pay-as-you-go. Issue a key from each service's dashboard, and enter it in the "API Key" field rather than writing it into the code. You can also choose the model name via 🔄 Fetch List (OpenRouter offers hundreds of options). Whether you can call the API directly from the browser depends on each service's CORS support (OpenRouter and DeepInfra support it; some services return Failed to fetch, in which case they cannot be used from the browser).

💡 What can you build? Idea collection

Anything that's "hard to write a formula for as correct, but you can tell good from bad just by looking" is usually well suited to IEC.

🎨
Logos / marks
Evolve shapes, coloring, and layout to find a logo you like.
🌸
Flower / plant shapes
Grow a plant you like from petal and branch genes.
🙂
Avatars / portraits
Choose facial features to approach an ideal face.
🎛️
Color palettes
Evolve color combinations. Find a palette you like.
🏛️
Building facades
Turn windows, columns, and proportions into genes and evolve the appearance.
🧩
Patterns / textures
Evolve repeating patterns or fabric designs by preference.
👗
Clothing / product shapes
Evolve shape and silhouette parameters.
🔤
Lettering decoration
Evolve font weight and ornamentation into logo text.
🎶
Moving shapes / animation
Evolve the motion itself by preference (ANIMATED).
Tips for success Organize "gene = X, appearance = Y" and ask a generative AI. If candidates look too similar, raise the mutation rate; if they're too scattered, lower it. This keeps exploration well balanced.

🔧 When things don't work

SymptomWhat to do
An error appears and nothing runsA line number and hint for the cause is shown. Read it first. If it's not fixed, paste the red error message as-is into a generative AI and ask it to fix it. ❔ Help also lists syntax that cannot be used.
The 9 individuals don't appearCheck whether you pressed ▶ Apply. The order is paste, then apply.
All the candidates look the sameRaising "mutation rate" and "mutation width" increases the differences. Also try crossover in 2-parent mode.
It should move but is staticAnimated models need ANIMATED=true. Ask the generative AI to "make it a moving animation".
Too fast / too slowAdjust with the animation speed slider (0.05×-8×). You can also change the speed individually via 🔍 Enlarge.
The generative AI's code doesn't workAsk again: "Please fix this according to the specification. Do not use document.*, import, or class."
With the free tier, the code cuts off partway / explanatory text gets mixed inPaste only the contents of the code block. If it's cut off, prompt it with "please continue", or ask again. The prompt already includes instructions to "output exactly one block, in full, without omission".
Note when pasting code Copy only the contents of the code block (```javascript ... ```), not the generative AI's entire reply. Using the "Copy" button at the top right of the code block automatically copies just the contents.

📚 References and sources

These are the representative original sources the built-in subjects draw on. All code is an independent implementation by this project (for the virtual creature, the code is independently implemented, drawing inspiration from existing research as noted below).

  • Interactive Evolutionary Computation (IEC) in general: Takagi, H. (2001). Interactive evolutionary computation: Fusion of the capabilities of EC optimization and human evaluation. Proceedings of the IEEE, 89(9), 1275–1296.
  • Branching shapes (Biomorphs): Dawkins, R. (1986). The Blind Watchmaker. Longman Scientific & Technical.
  • Interactive evolution of images: Sims, K. (1991). Artificial evolution for computer graphics. Computer Graphics (SIGGRAPH '91), 25(4), 319–328.
  • Flock (flocking / Boids): Reynolds, C. W. (1987). Flocks, herds and schools: A distributed behavioral model. Computer Graphics (SIGGRAPH '87), 21(4), 25–34.
  • Virtual creature (soft body, voxels): Bhatia, J., Jackson, H., Tian, Y., Xu, J., & Matusik, W. (2021). Evolution Gym: A large-scale benchmark for evolving soft robots. NeurIPS 2021. The idea of "evolving soft robots made of voxels" is drawn from Evolution Gym (github.com/EvolutionGym/evogym, MIT License); the code itself is independently implemented (no EvoGym source code is used).
  • Stained glass: a planar partition based on the Voronoi diagram.
  • Face, math art, and sound evolution: general applications of IEC, with no specific original source.
