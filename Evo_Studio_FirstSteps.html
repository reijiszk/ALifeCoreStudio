🤔 What is EVO Studio?

EVO Studio is a tool for running "evolution" (evolutionary computation) experiments in your browser. No installation needed: just double-click the file to use it.

A genetic algorithm (GA) is a way of solving problems modeled on biological evolution. You prepare a "population of individuals (candidate answers)," and by repeating evaluate → select → crossover (recombination) → mutate → next generation, "good answers" naturally get refined generation after generation.

In EVO Studio, the engine handles the entire GA mechanism (selection, crossover, mutation, elitism) for you. All you decide are three things: "the shape of the gene," "how to measure good vs. bad (the evaluation function)," and "how to draw the picture." And even that can be built by a generative AI and simply pasted in.

The idea behind this tool Recent advances in generative AI are reshaping the "understanding by building" (constructive) style of modeling in complex systems and artificial life. By giving a prompt with just the skeleton of an idea, not a complete specification, you can auto-generate a wide variety of models, have the AI explain them when you want to understand them, and refine ideas through dialogue. The catch is that letting the AI generate everything tends to produce wildly inconsistent results.
ALifeCoreStudio (the three studios, ABM / EVO / IEC) keeps a common framework for model construction, visualization, and analysis fixed, and lets generative AI produce only the essential parts of a model. This supports beginners with no programming experience giving free form to their ideas, students growing models together with AI, and researchers building prototypes quickly. By making it easy to generate possible models freely within a shared framework, we hope to accelerate the constructive approach to scientific understanding and spread the joy of imagining and running "what worlds could be."
All You Need A browser with EVO Studio (an HTML file) open, plus a generative AI service (ChatGPT, Gemini, Claude, etc.; the free tier is plenty)
Difference from ABM Studio ABM Studio is a tool for observing how phenomena emerge from individual rules. EVO Studio is a tool for searching for good answers through evolution. In Evo, the most important thing is defining the fitness function (fitness), a value where higher is better.

▶️ First, Try Running a Built-in Model

EVO Studio comes with models built in from the start. Let's try running one first.

1
Choose a model

Choose a model from the dropdown in the code bar at the bottom of the screen ("── Select a model ──").

2
Press ▶ Start Evolution

Generations advance, and the chart's fitness (best/average) rises. Press it again to pause. Use ⏭ 1 Gen to advance one generation at a time. Use ⟳ Reset to start over from a random initial population. It stops automatically once it reaches the "max generation" (the default is ⏹ Stop only; switch the selector on the right to 🔁 Loop to reset and repeat at that generation).

A Good Way to Watch First, choose "⑤ Traveling Salesman Problem (TSP)" and press ▶ Start Evolution. The tangled tour that starts out messy gradually straightens into a short, tidy route as generations pass. Lowering the run speed (generations/sec) makes the improvement easier to watch.
Handy Features to Know About
  • Run speed: the "Run speed" slider on the left is in generations/sec. Lower it to go slowly, raise it to speed through.
  • Compare results: evolve for a bit, then press 📸 Save Current to keep it overlaid on the chart.
  • Save data: use the chart's 💾 / ⬇ Save CSV to save results as a CSV for Excel.
  • 📦 Download ZIP: the 📦 Download ZIP button in "Save/Compare Experiments" bundles all data since initialization into a ZIP. It contains metadata.json (the experiment settings: parameters, stop condition, random seed, etc.), a .csv of per-generation fitness, data.json (all data), and the model code itself model.js. Handy for analyzing or reproducing later.
    Turn on Record states (time-shift / replay) before running and each generation's state is saved to frames.jsonl (leave it off when just observing, which is faster). Drop the exported ZIP onto the bundled ALifeCoreStudio_Viewer.html to replay each recorded generation with the model's own drawing (built-in, modified, or new models all work).
  • Watch it back while it runs: once states are being recorded, a timeline appears under the run buttons. LIVE is checked by default and the display follows the newest generation. Drag the bar (or uncheck LIVE) to go back to any earlier generation while evolution continues in the background, like the seek bar on a live video. ▶ plays the recorded generations back, an amber marker on each graph shows where you are, and re-checking LIVE returns you to the newest generation. How far back you can go is set by limit next to the interval (500 MB by default, up to no limit).
  • If it's heavy: lower "Population size," or for creature models, lower "Evaluation steps" to lighten the load.
  • 💾 HTML Export: use the button in the code bar to export a standalone HTML file that runs only the model currently running. It becomes a simple screen with no editing UI, handy for distribution, submission, or presentation.

👁️ Viewing Only the Best / the Whole Population

What's shown large on screen is the generation's best individual (the single one with the top score). Think of it as: many individuals are competing behind the scenes, and you're being shown the winner.

But looking at "the spread across the whole population" also matters for understanding evolution. You can switch this with the View toggle below the playback controls.

1
Best Only (default)

Shows only the best individual, enlarged. For creature models, you can see it walking, animated.

2
All Individuals

Shows the population's top individuals as tiles, ordered by fitness (the ★ in the top-left is the best). The Count slider next to it lets you choose how many individuals to show (4–36). The contents of each tile update as generations advance.

Tips for Using Each Mode Normally run with "Best Only," and occasionally switch to "All Individuals" to check the diversity (whether various shapes/routes coexist). This tells you whether evolution has "converged too much" or is "still exploring." If the tiles feel too small, lowering the count to something like 9 makes them bigger.

✏️ Modify a Running Model

If you think "I want to tweak this a bit more" about a built-in or custom model, use the "✏️ Modify Prompt" button. The current code and a modification instruction are copied together as a set.

📖 Explain Prompt and Model Name When you want to understand "how" the currently running model works, press 📖 Explain Prompt. A request that includes the current code is copied, so pasting it into a generative AI gets you a careful explanation with an overview, algorithm description, and pseudocode. Also, generated/modified code carries const TITLE = 'model name', which is reflected in the browser tab name, the "About" heading, and the filename used by 💾 Save .js (e.g., Mass-Spring_Creature.js).
1
Press "✏️ Modify Prompt"

It's in the code bar. The current code is automatically included in the prompt.

2
Paste it into a generative AI and write "what you want changed"

Just write what you want changed as bullet points under [What you want changed] at the end of the pasted prompt.

3
Replace all the code with what comes back

Select all in the code field (Ctrl+A), paste (Ctrl+V), and press "▶ Apply."

Example Modification Requests 💬

Try writing ideas like the following in the [What you want changed] bullet list.

Base Model Ideas for Modification Instructions to the AI
① Function Optimization
  • Change the evaluation function from Rastrigin to the Sphere function so the minimum value is 0.
  • Increase the number of variables from 2D to 3D (x, y, z).
② Mass-Spring Creature
  • Change fitness from "distance to the right" to "the highest point reached while jumping."
  • Add a gravity slider.
③ Soft-Body Creature
  • Change fitness from "movement speed" to "the height of the body's center of mass."
  • Place an obstacle on the ground and make it climb over it.
④ Knapsack
  • Increase the number of items to 50, with more variation in weight and value.
  • Widen the range of the capacity slider.
⑤ Traveling Salesman
  • Increase the number of cities to 40.
  • Arrange the cities in a circle (the shortest route should become a circle).
Tips for Modifying Trying to change too much at once tends to fail. It's best to request one or two small changes at a time and check that it works after each one.

✨ Have a Generative AI Build a New Model

EVO Studio has a "✨ New Model Prompt" button. Pressing it copies a spec sheet to hand to a generative AI onto your clipboard.

1
Press "✨ New Model Prompt"

It's in the code bar at the bottom of the screen. You're good once "Copied" appears.

2
Paste it into a generative AI and rewrite it

Paste it into the generative AI's chat box, rewrite the [Model to implement] field with the problem you want to solve, and send it.

3
Copy the code and paste it into EVO Studio

Copy just the contents of the code block (```javascript ... ```) that the generative AI produced, paste it into EVO Studio's code field, and press "▶ Apply."

Requests Like This Come Across Clearly 💬

The trick with a GA is to convey "what to make the gene, and what you want to maximize (or minimize)."

🙋
Example Student Input
Make a model with a real-valued gene that maximizes f(x,y)=sin(x)+cos(y)−0.1(x²+y²).
I'd like the search to be drawn as points on the x–y plane.
🙋
Example Student Input
I want to evolve a stick-figure-like creature so that periodic motion of its joint angles makes it walk as far right as possible.
I'd also like to see an animation of the best individual walking.
📋 Example Request to a Generative AI (what to write in the [Model to implement] field)
Please make a model that solves the problem you want to solve (e.g., shortest path, function optimization, walking creature) through evolution.

The gene (a candidate answer) is what (e.g., each city's order, real-valued parameters, shape and motion).
The fitness function (higher is better) is what you want to maximize (e.g., −route length, a function value, distance traveled).

Parameters you want to change with sliders: e.g., population size, mutation rate, number of cities (fine to omit if none)
If you want to see the best individual move, mention that too.

🤖 Connecting Directly to a Generative AI API (Local / Cloud)

Instead of copy-and-pasting to a generative AI, you can connect directly to an LLM running on your own PC (like LM Studio) and do the modification or creation entirely inside the Studio. This saves the hassle of pasting code back and forth, and lets you run everything locally without sending anything over the network. Any OpenAI-compatible API works (LM Studio, Ollama, OpenAI, etc.).

What You Need An OpenAI-compatible server such as LM Studio (free). Load one model and start the local server.
1
Start the server in LM Studio

Load a model → Start the "Local Server." Turn on "Enable CORS" in Server Settings (required for connecting from the browser).

2
Press "🤖 AI Generate"

It's in the code bar at the bottom of the screen. A settings panel opens; check the endpoint (default http://localhost:1234) and the model name. You can choose the model name via 🔄 Fetch List. Settings are remembered, so you won't need to redo this next time.

3
Choose "Modify / Create New," write your instructions, and press ▶ Send

Choose "✏️ Modify Existing Code" or "✨ Create New," write what you want, and send it. The generated code is automatically placed in the code field. Check it and press ▶ Apply to run it.

If the Connection Fails "Failed to fetch" is usually caused by the server not running, CORS not being enabled, or a wrong URL. First, try opening http://localhost:1234/v1/models directly in your browser to see if JSON comes back. If it does, LM Studio's side is fine. You can also type the model name in manually and still send the request.

Using Cloud Generative AI Services (OpenRouter, DeepInfra, OpenAI, etc.)

Not just local: OpenAI-compatible cloud APIs can also be used from the same panel. You don't need to run your own server; just enter each service's base URL in "Endpoint," the issued key in "API Key," and the model name.

ServiceEndpoint (Base URL)Example Model Names
OpenRouterhttps://openrouter.ai/api/v1openai/gpt-4o-mini, deepseek/deepseek-chat, etc.
DeepInfrahttps://api.deepinfra.com/v1/openaimeta-llama/Meta-Llama-3.1-8B-Instruct, etc.
OpenAIhttps://api.openai.com/v1gpt-4o-mini, etc.
Notes on Cloud Use These require an API key, and most are pay-as-you-go. Issue a key from each service's dashboard, and put it in the "API Key" field rather than writing it into code. You can also choose the model name via 🔄 Fetch List (OpenRouter lists hundreds). Whether it can be called directly from the browser depends on each service's CORS support (OpenRouter and DeepInfra support it; with some services you'll get Failed to fetch, in which case it can't be used from the browser).

💡 What Problems Can You Solve? Idea Gallery

If a problem has "something you want to optimize," a GA can usually handle it. Framing a request around your own field can even turn into a class report.

🗺️
Shortest Path / Delivery Planning
Traveling salesman, delivery route optimization. Make the order the gene.
📅
Scheduling
Timetables, shift schedules. Satisfy preferences while reducing constraint violations.
📈
Function Optimization
Maximum/minimum of a multivariable function. Explores valleys that hill-climbing can't escape.
🧠
Neural Network Weights
Evolve the weights of a small network to solve a simple control task.
🤖
Walking / Swimming Creatures
Evolve joint or spring motion to gain locomotion (Soft-Body Creature / Mass-Spring Creature).
🎨
Color Schemes / Layout
Evolve a color scheme using legibility, contrast, etc. as the fitness function.
🎒
Knapsack / Subset Sum
A classic constrained combinatorial optimization problem. Evolve an inclusion bit string.
🧩
Curve Fitting
Evolve the coefficients of a formula to fit data and discover a relationship (symbolic regression).
📡
Shape Optimization
Antenna shapes, truss structures, etc.; evaluate performance and evolve the shape.
Tips for Framing It Around Your Own Field Framing it as "gene = X, evaluation = maximize Y" before asking a generative AI tends to work well. It doesn't need to be perfectly precise; you can refine it later.

🔧 If Something Doesn't Work

SymptomWhat to Do
An error appears and it won't run The line number and a hint for the cause are shown. Read that first. If it's not fixed, paste the red error text as-is into a generative AI and ask it to "fix this." The ❔ Help panel in the top right also lists syntax that can't be used.
Nothing is displayed Check whether you pressed ▶ Apply. The order is: press Apply, then ▶ Start Evolution.
Fitness (the chart) isn't improving Try raising "Mutation rate" a bit to widen the search, raising "Selection pressure (tournament)" to make it easier to keep good individuals, or increasing "Population size." If the problem is too hard, reduce its scale.
It converges quickly to the same answer Raising "Mutation rate," lowering "Elitism," or increasing "Population size" helps preserve diversity. Check the spread using the All Individuals view.
It's too fast to see Lower "Run speed (generations/sec)." Use ⏭ 1 Gen if you want to watch one generation at a time.
It's heavy / stutters Lower "Population size." For creature models, lower "Evaluation steps." If showing All Individuals, reduce "Count."
The generative AI's code doesn't run Ask again: "Please fix this following the spec sheet. Don't use document.* / import / class."
On the free tier, the code cuts off partway / explanatory text gets mixed in Paste only the contents of the code block. If it cuts off, prompt it to "continue," or ask again. The prompt already includes instructions for "exactly one block, output the full text without abbreviation."
Note When Pasting Code Copy only the contents of the code block (```javascript ... ```), not the generative AI's entire reply. Using the "Copy" button in the top-right of the code block automatically copies just the contents.

📚 References & Sources

These are the key original sources the built-in models draw on as subject matter. All code is this project's own independent implementation (for the Soft-Body Creature, the code takes inspiration from existing research as noted below, but is implemented independently).

  • Genetic algorithms (GA): Holland, J. H. (1975). Adaptation in Natural and Artificial Systems. University of Michigan Press. / Goldberg, D. E. (1989). Genetic Algorithms in Search, Optimization, and Machine Learning. Addison-Wesley.
  • Mass-Spring Creature (evolving virtual creatures): Sims, K. (1994). Evolving virtual creatures. SIGGRAPH '94, 15–22. The origin of evolving virtual creatures. Sims evolved three-dimensional creatures made of articulated blocks, together with their neural controllers; the model here is not a reimplementation of that work but a far simpler two-dimensional mass-spring system, written independently in the spirit of that line of research.
  • Soft-Body Creature (voxels): Bhatia, J., Jackson, H., Tian, Y., Xu, J., & Matusik, W. (2021). Evolution Gym: A large-scale benchmark for evolving soft robots. NeurIPS 2021. The idea of "evolving soft robots made of voxels" is drawn from Evolution Gym (github.com/EvolutionGym/evogym, MIT License). All code, including the physics model (position-based dynamics), is independently implemented; no source code from EvoGym is used.
  • Knapsack problem / traveling salesman problem (TSP): Both are classic combinatorial optimization problems (see standard textbooks).
