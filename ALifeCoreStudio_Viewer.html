▶ ALifeCoreStudio Viewer Replay exported experiment data (ZIP) / 実験データ（ZIP）の再生

Load a ZIP exported with 📦 Download ZIP from ABM / EVO / IEC Studio, and each recorded step / generation is replayed by the model's own drawing code, for built-in, AI-modified, and newly created models alike.
ABM / EVO / IEC Studio の「📦 一式DL / Download ZIP」で書き出した ZIP を読み込むと、記録された各ステップ・世代の状態を、そのモデル自身の描画コードで再生します（組み込み・改変・新規作成のどのモデルでも動きます）。
Replay needs frames.jsonl inside the ZIP (the frames saved by Record states). IEC always records; for ABM / EVO, switch Record states on before exporting.
再生には ZIP 内の frames.jsonl（＝「状態を記録」で保存したフレーム）が必要です。IEC は常に記録されます。ABM / EVO は書き出し前に「状態を記録」をオンにしてください。
