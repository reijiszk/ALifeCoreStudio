Three studios, each a single self-contained HTML file. Click Run and it starts in this browser: nothing to install, build, or serve. Describe a model in plain language, let a generative AI write the code, paste it in, and run it.

First Steps Manual

New here? Open the First Steps guide for the studio you picked. It is the shortest path from opening the file to running a model you changed yourself.

Replay an experiment

Each studio exports a ZIP holding the model's own code, the settings, the random seed, and the recorded state of every step. Drop that ZIP onto the viewer and the run replays along a timeline, drawn by the model's own code, for built-in and AI-generated models alike.

Authoring with generative AI

ButtonWhat it does
✏️ Modify / ✨ New modelCopies a ready-to-paste prompt for ChatGPT, Gemini, Claude, or any chat LLM. One paste and apply click brings the answer back into the running model.
📖 ExplainAsks the AI to describe the current model in plain language and pseudocode, so you can understand it without reading the JavaScript.
🐍 Python conversionABM and EVO: converts the current model into an equivalent self-contained Python (matplotlib) script.
🤖 AI GenerateCalls an OpenAI-compatible endpoint directly from the page (a local server such as LM Studio, or a cloud provider) and inserts the generated code.

はじめてガイド マニュアル

はじめての方へ: まず選んだアプリのはじめてガイドをご覧ください。ファイルを開くところから、 自分で改変したモデルを動かすところまでを最短で案内します。

実験データの再生

各アプリは、モデルのコード・設定・乱数シード・各ステップの状態をまとめた ZIP を書き出せます。 その ZIP をビュワーにドロップすると、モデル自身の描画コードでタイムライン再生できます。組み込みモデルでも、 生成AIで作ったモデルでも動きます。

ボタンできること
✏️ 改変 / ✨ 新規作成そのまま貼り付けられるプロンプトをコピーします。ChatGPT・Gemini・Claude などの返答は「貼り付けて適用」の1操作で動作中のモデルに反映されます。
📖 説明現在のモデルの動作を、平易な言葉と疑似コードで説明してもらえます。JavaScript を読まずに理解できます。
🐍 Python変換ABM・EVO：現在のモデルを、同等で自己完結した Python（matplotlib）スクリプトへ変換します。
🤖 AI生成OpenAI互換エンドポイント（LM Studio などのローカルサーバ、またはクラウド）をページから直接呼び出し、生成されたコードを挿入します。
