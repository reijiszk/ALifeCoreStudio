IEC Studio v1.0: How to Use

✕ Close

IEC Studio is a tool for Interactive Evolutionary Computation. When you choose the one you like from the 3×3 grid of 9 individuals, it becomes the parent of the next generation of 9 individuals. Instead of writing an evaluation function as a formula, human preference is the selection pressure.

Two selection modes

  • 1 parent: mutation only: Click one individual you like, and 9 new individuals are born as small variations of that parent (the center ★ stays the parent unchanged).
  • 2 parents: crossover + mutation: Click two individuals in turn as parent A and parent B, and children are born by crossing over and mixing the two. Choose the crossover type (uniform / one-point / two-point) at bottom left.

Basic operation

  • Click an individual: generates the next generation. ⟳ Reset: returns to a random initial population.
  • 🔍 Enlarge (appears at bottom left when you hover over a cell): shows that individual larger. Animated models keep moving in the enlarged view, and you can adjust speed or pause. If you like it, select it with "Next generation from this individual".
  • Show lineage (checkbox below the grid): displays the history of the parent chosen in each generation, arranged left to right. Click a thumbnail to resume breeding from that ancestor (the branch you were on is kept; your next selection starts a new branch from that point), letting you try different branches.
  • Hovering over a cell reveals 📋 Genes. Clicking it loads and copies that individual's genes into the "Gene editor" on the right.
  • Operator parameters: sliders such as mutation rate and mutation width (applied starting from the next generation). Click ⓘ for an explanation.
  • ⛶ Fullscreen (header): enlarges the grid of 9 individuals to fill the screen. Handy for projecting onto a screen so a whole classroom can view the candidates while choosing. Selecting by click and generating the next generation still work as usual. While shown, the screen is reduced to a minimal display with just the generation counter and ⟳ Reset / ✕ Exit fullscreen (change mode, crossover type, etc. after returning to the normal view). You can also exit with the Esc key.

Genes (definition and center individual)

  • On the right, chips show the definition of the genes currently in use (the length of the numeric array and each gene's range, GENE_RANGES) as well as the genes of the center individual (★) itself.
  • In the "Gene editor" you can edit the JSON array directly and place it in the center / expand it to all cells. Useful for saving and reproducing individuals you like.

Animated individuals

Add const ANIMATED = true to the code and define initState / stepState / drawFrame, and each cell will move (e.g., flocking). Use Animation on the right to play/stop and adjust speed.

Writing code (conventions shared with ABM / EVO Studio)

Define the model in the Code field below. Three functions are required: createInitialGenome() / mutateGenome(genome, params) / drawPhenotype(ctx, genome, W, H) (for animation, the three functions above replace draw). GENE_RANGES and PARAM_DEFS are optional. The code is evaluated with new Function(), and class / document.* / window.* / fetch / setTimeout / import, etc. cannot be used (using them shows an error with a line number). When asking an AI to make changes, use ✏️ Modify Prompt / ✨ New Model Prompt. Use 💾 Save .js / 📂 Open to save and load models. 💾 HTML Export writes out a standalone HTML file that runs only the currently running model (no code-editing / AI-generation UI), handy for distribution or classroom handouts.

🔊 Sound: toggle on/off with 🔊 in the header. Use Sound.beep(...) / Sound.note(...) to produce sound. Models that define playSound(genome) (e.g., Sound evolution) show a ▶ Play sound button on each candidate so you can listen before choosing.
