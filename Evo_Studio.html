EVO Studio v1.0: How to Use

✕ Close

EVO Studio is a tool for experiencing genetic algorithms (GA). It updates a population generation by generation through "evaluate → select → crossover → mutate → next generation," letting you watch in real time as individuals with higher fitness (evaluation values) get selected. The engine handles the GA machinery; all you write is fitness (the evaluation function), draw (rendering), and similar functions.

support for phones/tablets (the layout automatically stacks vertically on narrow screens), a 🐍 Python Prompt (copies a prompt that converts the current model into a matplotlib-based Python script + requirements.txt), Y/X axis range settings for charts (toggle auto-scale/manual from each chart's ⚙ Axis), and the max-generation default changed to "⏹ Stop only" (switch the adjacent selector to 🔁 Loop if you want the old repeating behavior).

Two Built-in Models

  • ① Bit-String GA: Function Optimization: Decodes a 32-bit gene into real numbers x, y and optimizes an evaluation function (by default, minimizing the Rastrigin function). Individuals are shown as points in the search space, converging on the optimum (the origin).
  • ② Mass-Spring Creature: Evolving a 2D Virtual Creature: A physics model walks a virtual creature made of four point masses connected by muscle springs, evaluating and evolving it by the distance traveled to the right. The best individual is shown walking in place.

Basic Controls

  • ▶ Start Evolution / ⏸ Stop: Run/stop the evolution. ⏭ 1 Gen advances just one generation.
  • ⟳ Reset: Rebuilds a random initial population using the current parameters.
  • Run speed: Generations advanced per second (roughly 0.1–60 gen/s, logarithmic). Set it below 1 to spend more time on each generation and closely observe a creature's walk; raise it to speed through function optimization.
  • CoM line (right of View): For walking models (mass-spring creature / soft-body creature), shows the center-of-mass position (vertical dashed line) and height (horizontal line). Makes the walking rhythm and vertical body motion easy to see at a glance.
  • 🔍 Zoom Best: Enlarges the best individual found so far. Walking models animate in place (speed adjustable, can be paused), and you can save an 🖼 image (PNG) or ⏺ recording (WebM/MP4). It switches automatically when a better individual is found.
  • Max generation: With the default ⏹ Stop only, evolution stops once it reaches the specified generation (it does not restart). Switch the adjacent selector to 🔁 Loop to automatically reset and repeat at that generation. Draw skipping skips frames to prioritize computation when things get heavy.

Gene Panel (Definition & Best Individual)

  • The "Genes (Definition & Best Individual)" panel on the right shows the definition of the gene currently in use (type, length, range, and description), plus the gene itself of the individual with the highest fitness in the current generation.
  • Bit strings are shown as a grid (filled = 1), and real numbers as numeric chips (the bar shows magnitude within the range); both update as generations advance.
  • In your own models, defining geneInfo (a description) and geneView(genome, params) (a split display) makes this easier to read (if omitted, the gene is shown as-is).

★ Define Fitness (the Evaluation Method) Yourself

  • fitness(genome, params) in the code field is the evaluation function. It returns a value where higher is better (maximization). To minimize a function, flip the sign and return -f.
  • Examples: in function optimization, change rastrigin to rosenbrock; in the mass-spring creature, change return r.distance to return r.maxHeight to evolve a "creature that jumps high," and so on.
  • The gene format is set with GENE = { type:'bit'|'real', length, min, max }. Use decode() to convert the gene into a meaningful value (coordinates, a design, etc.).

Parameters (Tuning the GA)

  • Population size (popSize), mutation rate (mutationRate), crossover rate (crossoverRate), elitism, and selection pressure (tournamentK) are the GA parameters the engine recognizes.
  • Live (default): things like mutation rate take effect immediately from the next generation. Changing a value that requires re-initialization, such as population size, shows a "reset needed" hint.

Save & Compare Experiments

  • 📸 Save Current: Saves the current fitness chart and parameters, letting you overlay them on the chart as faint lines for comparison, handy for showing A/B how convergence changes with a different mutation rate, for example.
  • Each chart also offers ⬇ CSV (clipboard), 💾 (file), a combined ⬇ Save CSV, and ⏺ Record.

Notes on Writing Code (Avoiding Errors)

Code is evaluated with new Function(). class / document.* / window.* / addEventListener / fetch / setTimeout / import, etc. cannot be used. Using them shows a line number and a hint when you apply the code. When asking an AI to make changes, copy the ✏️ Modify Prompt / ✨ New Model Prompt and use it.

💾 HTML Export: Exports a standalone HTML file that runs only the model currently running (no code-editing / AI-generation UI). Handy for distribution or classroom handouts.

🔊 Sound: Use the 🔊 button in the header to toggle sound on/off. When a model calls Sound.beep(...) or Sound.note(...), a sound plays (enabled after the first click).
