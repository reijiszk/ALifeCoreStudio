EVO Studio v1.0 — つかいかた

✕ 閉じる

EVO Studio は 遺伝的アルゴリズム（GA） を体験するツールです。個体群を「評価 → 選択 → 交叉 → 突然変異 → 次世代」と世代ごとに更新し、適応度（評価値）が高い個体が選ばれていく様子をリアルタイムに観察できます。GA の仕組みはエンジン側が担当し、あなたは fitness（評価関数）や draw（描画）などを書くだけです。

スマホ・タブレット対応（画面幅が狭いとレイアウトが自動で縦積みに），🐍 Python化プロンプト（現在のモデルを matplotlib 版 Python スクリプト＋requirements.txt に変換するプロンプトをコピー），グラフの縦軸・横軸の範囲設定（各グラフの ⚙ 軸 から自動調整／手動設定を切り替え），最大世代の既定を「⏹ 停止のみ」に変更（従来通り繰り返したい場合は隣のセレクタを 🔁 ループ に切り替え）を追加しました。

2つの内蔵モデル

  • ① ビット列GA ─ 関数最適化：32ビットの遺伝子を実数 x, y にデコードし、評価関数（既定は Rastrigin の最小化）を最適化します。探索空間に個体が点で表示され、最適点（原点）に集まっていきます。
  • ② 質点バネ生物 ─ 2D仮想生物の進化：4つの質点を筋肉バネでつないだ仮想生物を物理モデルで歩かせ、右へ進んだ距離を評価して進化させます。最良個体がその場で歩く様子を表示します。

基本操作

  • ▶ 進化開始 / ⏸ 停止：進化の実行・停止。⏭ 1世代 は1世代だけ進めます。
  • ⟳ 初期化：現在のパラメータでランダムな初期個体群を作り直します。
  • 実行速度：1秒あたりに進める世代数（約0.1〜60 世代/秒、対数）。1未満にすると1世代に時間をかけて生物の歩行をじっくり観察でき、関数最適化を速く回したいときは大きくします。
  • 重心線（表示の右）：歩行モデル（質点バネ生物／ソフトボディ生物）で重心の位置（縦の破線）と高さ（横線）を表示します。歩行のリズムや体の上下動が一目で分かります。
  • 🔍 最良を拡大：現在までの最良個体を大きく表示します。歩行モデルはその場で動き（速度・一時停止可）、🖼 画像(PNG)や⏺ 録画（WebM/MP4）で保存できます。より良い個体が見つかると自動で切り替わります。
  • 最大世代：既定の ⏹ 停止のみ では、指定世代に達すると停止します（最初に戻りません）。隣のセレクタを 🔁 ループ に切り替えると、その世代で自動的に初期化して繰り返します。描画間引きは重いとき計算を優先して描画を間引きます。

遺伝子パネル（定義と最良個体）

  • 右側の「遺伝子（定義と最良個体）」に、いま使われている遺伝子の定義（型・長さ・範囲と説明）と、現世代で最も適応度が高い個体の遺伝子そのものが表示されます。
  • ビット列はマス目（塗り=1）で、実数は数値チップ（バーは範囲内の大きさ）で表示され、世代が進むと更新されます。
  • 自作モデルでは geneInfo（説明文）と geneView(genome, params)（分割表示）を定義すると、より分かりやすく表示できます（省略時は遺伝子をそのまま表示）。

★ 適応度（評価の方法）を自分で決める

  • コード欄の fitness(genome, params) が評価関数です。大きいほど良い値を返します（最大化）。最小化したい関数は符号を反転して return -f とします。
  • 例：関数最適化で rastrigin を rosenbrock に変える、質点バネ生物で return r.distance を return r.maxHeight に変えて「高く跳ぶ生物」を進化させる、など。
  • 遺伝子の形式は GENE = { type:'bit'|'real', length, min, max } で決めます。decode() を使うと遺伝子を意味のある値（座標・設計）に変換できます。

パラメータ（GA の調整）

  • 個体数 popSize・突然変異率 mutationRate・交叉率 crossoverRate・エリート保存 elitism・選択圧 tournamentK はエンジンが認識する GA パラメータです。
  • 即時反映（既定）：突然変異率などは次の世代からすぐ反映されます。個体数のように初期化が必要な値を変えると「初期化が必要」のヒントが出ます。

実験の保存・比較

  • 📸 現在を保存：いまの適応度グラフとパラメータを保存し、グラフにうすい線で重ねて比較できます。「突然変異率を変えると収束はどう変わる？」を A / B で見せる用途に。
  • 各グラフの ⬇ CSV（クリップボード）・💾（ファイル）、まとめて ⬇ CSV保存、⏺ 録画 も使えます。

コードを書くときの注意（エラー対策）

コードは new Function() で評価されます。class / document.* / window.* / addEventListener / fetch / setTimeout / import 等は使えません。使うと適用時に行番号とヒントを表示します。改変を AI に頼むときは ✏️ 改変プロンプト / ✨ 新規作成プロンプト をコピーして使ってください。

💾 HTML出力：今動かしているモデルだけをそのまま実行できる独立した HTML ファイル（コード編集・AI生成 UI なし）を書き出せます。配布や授業での配布物に便利です。

🔊 音：ヘッダの 🔊 ボタンで音のオン/オフを切り替えられます。モデルが Sound.beep(...) や Sound.note(...) を呼ぶと音が鳴ります（最初のクリック後に有効になります）。
