ABM Studio v1.0 — つかいかた

✕ 閉じる

ABM Studio は setup / step / draw の3つの関数でエージェントベースモデルを記述し、パラメータをリアルタイムに変えながら挙動とグラフを観察できるツールです。スマートフォン・タブレットの画面幅にも対応しています。

基本操作

  • ▶ 実行 / ⏸ 停止：モデルの開始・停止。⏭ 1 tick は1ステップだけ進めます。
  • ⟳ 初期化：現在のパラメータで初期状態を作り直します。
  • 実行速度：1フレームあたりのステップ数（t/f）。約0.1〜60まで対数で調整でき、1 未満にすると数フレームに1回だけ進むのでゆっくり観察できます。描画間引き：N フレームに1回だけ描画して計算を高速化します（エージェントが多いときに有効）。
  • 最大 tick：トグルをONにすると、指定 tick に到達したときの挙動を選べます（右に出る到達時セレクタ、既定は ⏹ 停止のみ）。⏹ 停止のみ＝初期化せず、その場で一時停止します（最初に戻りません）。🔁 ループに切り替えると、自動的に初期化して最初から繰り返します。トグルOFFなら最大 tick は無視されます。

パラメータの反映方法

  • 即時反映（既定）：スライダーを動かすと、実行中のモデルに step 経由で即座に反映されます。これまでの履歴（グラフ）は消えません。
  • 自動初期化：スライダーを動かすと自動で初期化します。
  • 初期配置にだけ使われる値（密度・初期人数など）は step では効かないため、変更すると「初期化が必要」のヒントが出ます。今すぐ初期化を押すか ⟳ 初期化 で反映してください。勝手に履歴が消えることはありません。

実験の保存・比較

  • 📸 現在を保存：いまのグラフ（実行結果）とパラメータ一式を保存し、グラフ上にうすい線で重ねて比較できます。条件 A / B を切り替えて発表する用途に。
  • 各実験は 👁 で表示/非表示、✕ で削除できます。⬇ CSV保存で全グラフ＋保存実験をまとめて CSV ファイルに書き出せます。
  • 各グラフの ⬇ CSV（クリップボード）・💾（ファイル）・🖼 画像も利用できます。

グラフの縦軸・横軸の範囲設定

  • 各グラフ右上の ⚙ 軸 を押すと、縦軸（Y）・横軸（X, tick）それぞれの範囲設定欄が開きます。
  • 自動調整（既定）：これまで通り、データの範囲に合わせて軸を自動で調整します。
  • 手動設定：min／max を数値で指定して固定します。特定の範囲を拡大して見たい時や、複数のグラフの見た目を揃えたい時に使ってください。

コードを書くときの注意（エラー対策）

コードは new Function() で評価されます。次の構文は使えません。使うと適用時にエラーになり、コード欄の下に原因の行番号とヒントを表示します。

  • class キーワード → オブジェクトリテラル {} で代替
  • document.* / window.* などの DOM 操作、addEventListener
  • fetch / XMLHttpRequest（外部通信）
  • setTimeout / setInterval（非同期処理）
  • import / export 文

ChatGPT に改変を頼むときは、コード欄の ✏️ 改変プロンプト / ✨ 新規作成プロンプト をコピーして使うと、仕様と禁止事項・「簡単な解説コメントを付ける」指示まで含まれた状態で依頼できます。

🐍 Python化プロンプト：現在のコードを、単体で動く Python スクリプト（matplotlib 使用）＋ requirements.txt に変換させるプロンプトをコピーします。生成AIに貼り付けると、2つのコードブロック（Pythonスクリプトと requirements.txt）で返ってきます。

💾 HTML出力：今動かしているモデルだけをそのまま実行できる独立した HTML ファイル（コード編集・AI生成 UI なし）を書き出せます。配布や授業での配布物に便利です。

🔊 音：ヘッダの 🔊 ボタンで音のオン/オフを切り替えられます。モデルが Sound.beep(...) や Sound.note(...) を呼ぶと音が鳴ります（最初のクリック後に有効になります）。鳴らしすぎないよう，イベント時だけ鳴らすのがコツです。

保存・読み込み

  • 💾 .js保存：現在のコードを .js ファイルとして保存。📂 開く：保存した .js / .txt を読み込みます。
  • ⏺ 録画：キャンバスを動画保存。形式は隣のメニューで MP4 / WebM / 自動 を選べます（環境が対応していない形式は自動的に WebM になります）。

パラメータの意味（ⓘ）

各パラメータ名の横に ⓘ がある場合は、ポインタを乗せると説明が表示されます。コードの PARAM_DEFS に help: '説明文' を足すと、その説明が表示されます。
