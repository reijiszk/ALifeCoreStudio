IEC Studio v1.0 — つかいかた

✕ 閉じる

IEC Studio は 対話型進化計算（Interactive Evolutionary Computation） のツールです。3×3 の9個体の中から「いいな」と思うものをあなたが選ぶと、それを親にして次の世代9個体が作られます。評価関数を式で書くのではなく、人間の好みが選択圧になります。

2つの選び方（モード）

  • 1親 ─ 変異のみ：気に入った個体を1つクリックすると、それを親に少しずつ変えた9個体が生まれます（中央 ★ は親そのまま）。
  • 2親 ─ 交叉＋変異：親 A・親 B の2個体を順にクリックすると、両者を交叉して混ぜた子が生まれます。交叉方式（一様／一点／二点）は左下で選べます。

基本操作

  • 個体をクリック：次世代を生成。⟳ 初期化：ランダムな初期個体群に戻します。
  • 🔍 拡大（各セルにマウスを乗せると左下に表示）：その個体を大きく表示します。アニメのモデルは拡大画面で動き、速度や一時停止も調整可能。気に入ったら「この個体から次世代」で選べます。
  • 系統を表示（グリッド下のチェック）：各世代で選んだ親の履歴を左→右に並べて見せます。サムネイルをクリックするとその祖先から育種をやり直せ（いまの系統は消えず、次に選んだ時点から新しい系統として記録されます）、枝分かれを試せます。
  • 各セルにマウスを乗せると 📋 遺伝子 が出ます。押すとその個体の遺伝子を右の「遺伝子エディタ」に読み込み＆コピーします。
  • 演算パラメータ：変異率・変異幅などのスライダー（次に生成する世代から反映）。ⓘ で説明が出ます。
  • ⛶ 全画面（ヘッダー）：9個体のグリッドを画面いっぱいに拡大表示します。プロジェクタに投影して教室全体で候補を見ながら選ぶのに便利です。クリックによる選択・世代の生成はそのまま使えます。表示中は世代表示と ⟳ 初期化・✕ 全画面終了 だけの最小限の画面になります（モード切替や交叉方式などは通常表示に戻ってから変更してください）。Esc キーでも終了できます。

遺伝子（定義と中央個体）

  • 右側に、いま使われている遺伝子の定義（数値配列の長さ・各遺伝子の範囲 GENE_RANGES）と、中央個体（★）の遺伝子そのものがチップで表示されます。
  • 「遺伝子エディタ」では JSON 配列を直接編集して 中央に配置 / 全体に展開 できます。気に入った個体を保存・再現するのに使えます。

アニメーション個体

コードに const ANIMATED = true を加え、initState / stepState / drawFrame を定義すると、各セルが動きます（例：群れ）。右のアニメーションで再生／停止・速度を調整できます。

コードの書き方（ABM / EVO Studio と共通の作法）

下のコード欄でモデルを定義します。必須は createInitialGenome() / mutateGenome(genome, params) / drawPhenotype(ctx, genome, W, H) の3つ（アニメ時は draw の代わりに上記3つ）。GENE_RANGES と PARAM_DEFS は任意です。コードは new Function() で評価され、class / document.* / window.* / fetch / setTimeout / import 等は使えません（使うと行番号つきでエラー表示）。改変を AI に頼むときは ✏️ 改変プロンプト / ✨ 新規作成プロンプト を使ってください。💾 .js保存 / 📂 開く でモデルを保存・読み込みできます。💾 HTML出力 を使うと、今動かしているモデルだけをそのまま実行できる独立した HTML ファイル（コード編集・AI生成 UI なし）を書き出せます。配布や授業での配布物に便利です。

🔊 音：ヘッダの 🔊 でオン/オフ。Sound.beep(...) / Sound.note(...) で発音できます。playSound(genome) を定義したモデル（例：音の進化）では各候補に ▶ 鳴らす が出て，聴いてから選べます。
