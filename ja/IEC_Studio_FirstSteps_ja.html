🤔 IEC Studio って何？

IEC Studio は，ブラウザで動く「対話型進化計算（IEC）」のツールです．インストール不要．ファイルをダブルクリックするだけで使えます．

ふつうの進化計算（GA）は，良し悪しを数式（評価関数）で測ります．IEC では，その役割をあなたの「好み」が担います．3×3 の9個体から「いいな」と思うものをクリックすると，それを親にして次の世代9個体が作られ，少しずつ好みの形へ進化していきます．

あなたが決めるのは「遺伝子の形」「遺伝子から絵をどう描くか」だけ．それも 生成AI に作ってもらって貼り付けるだけでかまいません．

このツールのねらい（考え方） 近年の生成AIの進展は，複雑系や人工生命の「作って理解する（構成論的）」モデリングを大きく変えつつあります．プロンプトで骨子を与えれば，完全な仕様でなくても様々なモデルを自動生成でき，必要に応じて AI に説明してもらって理解したり，対話しながらアイデアを洗練したりできます．ただし，全部を AI に任せると出来上がるものがバラバラになりがちです．
ALifeCoreStudio（ABM・EVO・IEC の3スタジオ）は，モデル構築・可視化・分析の共通の枠組みを固定したうえで，モデルの本質的な部分だけを生成AIで生み出せるようにした道具です．これにより，プログラミング未経験の初心者が発想を自由に形にする／学生が AI と協働してモデルを育てる／研究者が素早くプロトタイプを作る，といった使い方ができます．
枠組みの中で可能なモデルを自由に生み出すことを通じて，構成論的アプローチによる科学的理解を加速し，「どんな世界がありうるか」を思い描いて動かす楽しさを広げたい——それがこのツールのねらいです．
これだけあれば OK IEC Studio（HTML ファイル）を開いたブラウザ ＋ 生成AIサービス（ChatGPT・Gemini・Claude など，無料版で十分）
Evo／ABM Studio との違い Evo は評価関数で，ABM は個体のルールで動きます．IEC のいちばんの特徴は，評価関数を書かず「人が選ぶ」こと．美しさ・好みなど，式にしにくい価値を進化させられます．

▶️ まずビルトインモデルを動かしてみよう

IEC Studio には最初からモデルが入っています．まずそれを動かしてみましょう．

1
モデルを選ぶ

画面下のコードバーにあるドロップダウンからモデルを選びます．9個の候補が表示されます．

2
気に入った個体をクリック

選んだ個体を親に，次の世代9個体が作られます．これをくり返すだけで，好みの形へ進化します．⟳ 初期化 でランダムな初期集団からやり直せます．

おすすめの見方 まず「枝分かれ図形」を選び，少しでも「いいな」と思う形を次々クリックしてみてください．10回ほど選ぶと，最初とはまるで違う「自分好みの生き物」が育っていきます．「選ぶだけで形が育つ」進化の体験ができます．
知っておくと得な機能
  • 1親 / 2親モード：1個体を選んで変異させるか，2個体を選んで交叉（かけ合わせ）するかを切り替えられます．
  • 🔍 拡大：各セルにマウスを乗せると出るボタンで，その個体を大きく表示（アニメは動きます）．じっくり見てから選べます．
  • 系統を表示：これまで選んだ親の履歴が並びます．サムネイルをクリックすると，その祖先から育種をやり直せ（巻き戻し），枝分かれを試せます．
  • 📦 データ一式DL：系統チェックの隣の 📦 データ一式DL で，初期化以降のデータを ZIP にまとめて保存できます．中身は，各世代の全9個体 frames.jsonl，選んだ親の系統 lineage.csv，現在の9個体 population.csv，実験設定（選択モード・交叉方式・パラメータ・乱数シード 等）の metadata.json，全データの data.json，そしてモデルのコードそのもの model.js です．
    書き出した ZIP をリポジトリ直下の ALifeCoreStudio_Viewer.html にドロップすると，各世代の9個体を，そのモデル自身の絵で並べてタイムライン再生できます（選んだ個体には ★・組み込み／改変／新規どれでも動作）．IEC は軽いので状態は常に記録され，オン／オフの操作は不要です．
  • このモデルの概要：右パネル上部に，遺伝子・表現型・選び方の説明が出ます．
  • 変異率・変異幅：大きいほど子が親から大きく変わります．代わり映えしないときは上げる．
  • ⛶ 全画面：ヘッダーのボタンで9個体グリッドだけを画面いっぱいに表示．プロジェクタ投影や教室での一斉閲覧に．
  • 💾 HTML出力：いま動かしているモデルを，編集UIなしの単体HTMLファイルとして書き出せます．配布・提出・発表用の保存に．

👁️ 系統・拡大・概要の見かた

IEC ならではの便利な3つの見かたを覚えておきましょう．

1
系統を表示（選んだ親の履歴）

グリッド下のチェックを入れると，各世代で選んだ親が左→右に並びます．サムネイルをクリックするとその祖先から育種をやり直せ，別の枝を試して比べられます．

2
🔍 拡大（大きく観察）

各セルにマウスを乗せると左下に出ます．その個体を大きく表示し，アニメのモデルは動く様子を速度を変えて観察できます．気に入ったら「この個体から次世代」で選べます．

3
このモデルの概要

右パネル上部に，遺伝子（何が変わるか）・表現型（どう絵になるか）・選び方が書かれています．まず読むと選びやすくなります．

使い分けのコツ 迷ったら変異率を上げて多様な候補を出し，🔍 拡大でじっくり見てから選ぶ．行き詰まったら系統から前の祖先に戻って別方向へ．これだけで探索の幅が大きく広がります．

✏️ 動いているモデルを改変しよう（まずはここから）

いちばん簡単な入り口がこれです．ビルトインのモデルを少し変えるだけで，自分の関心に近づけられます．「✏️ 改変プロンプト」ボタンを押すと，現在のコードと改変指示がセットでコピーされます．

📖 説明プロンプト と モデル名 いま動かしている題材の「仕組み」を知りたいときは 📖 説明プロンプト を押します．現在のコードを含む説明依頼がコピーされるので，生成AI に貼ると概要・アルゴリズムの説明・疑似コードで丁寧に解説してくれます．また生成・改変されたコードには const TITLE = 'モデル名' が付き，ブラウザのタブ名・「説明」の見出し・💾 .js保存 のファイル名（例 枝分かれ図形.js）に反映されます．
1
「✏️ 改変プロンプト」を押す

コードバーにあります．現在のコードが自動的にプロンプトに含まれます．

2
生成AI に貼り付けて「変えたいこと」を書く

貼り付けたプロンプトの末尾にある【改変したい内容】に，変えたい内容を日本語で1〜2 項目ずつ箇条書きします．

3
返ってきたコードを全部入れ替える

コード欄で全選択（Ctrl+A）して貼り付け（Ctrl+V），「▶ 適用」を押します．

モデル別・改変リクエストの例（各2つ）💬

ベースモデル生成AI への改変指示のアイデア
🌿 枝分かれ図形
  • 枝分かれの最大本数や深さを増やして，もっと複雑な形になるようにして．
  • 色を遺伝子に加えて，枝ごとに色が変わるようにして．
🐦 群れ（フロッキング）
  • 個体数を増やして大きな群れにして．
  • 捕食者を1匹加えて，群れが逃げる動きが出るようにして．
🪟 ステンドグラス
  • 領域（ボロノイの種点）の数を増やして，細かい模様にして．
  • 配色を寒色系／暖色系に寄せられるパラメータを加えて．
🧬 ソフトボディ生物
  • ボクセルを 6×6 に拡大して，より複雑な体にして．
  • 水中（抵抗が大きい）設定にして，泳ぐような動きが出るようにして．
🌀 数式アート
  • 左右対称・回転対称の模様になりやすくして．
  • 使う色数を増やして，もっとカラフルにして．
🙂 顔の進化
  • 髪型のバリエーションを遺伝子に加えて．
  • 表情（口角・眉の角度）を遺伝子にして，笑顔や困り顔が出るようにして．
🎵 音の進化
  • 音の数を8音から16音に増やして，もっと長いメロディにして．
  • リズム（音の長さ）も遺伝子に加えて，変化をつけられるようにして．
改変のコツ 一度に大きく変えようとすると失敗しやすいです．小さな変更を 1〜2 個ずつ頼んで，動くたびに確認していくのがおすすめです．

✨ 生成AI に新しいモデルを作ってもらおう

改変に慣れたら，ゼロから新しいモデルも作れます．「✨ 新規作成プロンプト」ボタンを押すと，生成AI に渡すための仕様書がクリップボードにコピーされます．

1
「✨ 新規作成プロンプト」を押す

画面下部のコードバーにあります．「コピーしました」と出れば OK．

2
生成AI に貼り付けて書き換える

生成AI のチャット欄に貼り付け，【作りたいもの】の欄を進化させたい対象に書き換えて送信します．

3
コードをコピーして IEC Studio に貼る

生成AI が出力したコードブロック（```javascript ... ```）の中身だけをコピーして，コード欄に貼り付け「▶ 適用」を押します．

こんなふうに頼むと伝わりやすい 💬

IEC では「遺伝子（何が変わるか）と，遺伝子からどんな絵を描くか」を伝えるのがコツです．良し悪しは人が選ぶので，評価関数は要りません．

🙋
学生の入力例
花の形を「好み」で進化させたい．
花びらの枚数・色・とがり具合を遺伝子にして，9個の花を描いて．クリックで似た花が9個出るように．
🙋
学生の入力例
幾何学的な「ロゴ」を進化させたい．
図形の数・回転・配色を遺伝子にして，対称性のある模様が出やすいようにして．
📋 生成AI へのリクエスト例（【作りたいもの】欄に書く内容）
進化させたい対象（例：花・ロゴ・模様・生き物） を「好み」で進化させるモデルを作ってください．

遺伝子（少しずつ変わるもの）は 何か（例：色・枚数・角度・大きさ）．
遺伝子からの絵の描き方は どんな見た目か（例：放射状の花・幾何学模様）．

動く絵にしたい場合は，その旨も書いてください（アニメーション対応）．
良し悪しは人がクリックで選ぶので，評価関数は不要です．

🤖 生成AI の API に直接つないで生成する（ローカル / クラウド）

生成AI にコピー＆ペーストする代わりに，自分のPCで動く LLM（LM Studio など）に直接つないで，改変や新規作成を Studio の中だけで完結させることもできます．コードを貼ったり戻したりする手間がなく，ネットに送らず手元で動かせるのが利点です．OpenAI 互換 API なら何でも使えます（LM Studio・Ollama・OpenAI など）．

必要なもの LM Studio（無料）などの OpenAI 互換サーバ．モデルを1つロードし，ローカルサーバを起動しておきます．
1
LM Studio でサーバを起動する

モデルをロード →「Local Server」を Start．Server Settings で「Enable CORS」を ON にしておきます（ブラウザから接続するために必須）．

2
「🤖 AI生成」を押す

画面下部のコードバーにあります．設定パネルが開くので，エンドポイント（既定 http://localhost:1234）とモデル名を確認します．モデル名は 🔄 一覧取得 で選べます．設定は記憶されるので次回からは不要です．

3
「改変／新規作成」を選び，指示を書いて ▶ 送信

「✏️ 既存コードを改変」か「✨ 新規作成」を選び，やりたいことを書いて送信します．生成されたコードは自動でコード欄に入ります．内容を確認して ▶ 適用 で実行します．

うまく繋がらないとき 「Failed to fetch」はサーバ未起動・CORS 未設定・URL 違いが主な原因です．まずブラウザで http://localhost:1234/v1/models を直接開いて JSON が出るか確認してください．出れば LM Studio 側は正常です．モデル名は手入力でも送信できます．

クラウドの生成AIサービスを使う（OpenRouter・DeepInfra・OpenAI など）

ローカルだけでなく，OpenAI 互換のクラウド API も同じパネルから使えます．自分でサーバを立てる必要はなく，「エンドポイント」に各サービスのベースURL，「API キー」に発行したキー，モデル名を入れるだけです．

サービスエンドポイント（Base URL）モデル名の例
OpenRouterhttps://openrouter.ai/api/v1openai/gpt-4o-mini，deepseek/deepseek-chat など
DeepInfrahttps://api.deepinfra.com/v1/openaimeta-llama/Meta-Llama-3.1-8B-Instruct など
OpenAIhttps://api.openai.com/v1gpt-4o-mini など
クラウド利用の注意 これらは API キーが必須で，多くは従量課金です．キーは各サービスのダッシュボードで発行し，コードに書かず「API キー」欄に入れてください．モデル名は 🔄 一覧取得 でも選べます（OpenRouter は数百種類出ます）．ブラウザから直接呼べるかは各サービスの CORS 対応によります（OpenRouter・DeepInfra は対応。サービスによっては Failed to fetch になり，その場合はブラウザからは使えません）．

🔧 うまくいかないときは

症状対処法
エラーが出て動かない原因の行番号とヒントが日本語で出ます．まず読む．直らなければ赤いエラー文をそのまま 生成AI に貼って「直して」と頼む．❔ ヘルプ に使えない書き方の一覧もあります．
9個が表示されない▶ 適用 を押したか確認．貼り付け→適用の順です．
候補が全部同じに見える「変異率」「変異幅」を上げると違いが大きくなります．2親モードで交叉も試す．
動くはずが静止しているアニメ用のモデルは ANIMATED=true が必要．生成AI に「動くアニメにして」と頼む．
速い／遅いアニメ速度スライダー（0.05×〜8×）で調整．🔍 拡大 でも個別に速度を変えられます．
生成AI のコードが動かない「仕様書に従って修正してください．document.*・import・class は使わないでください」と再依頼．
無料版でコードが途中で切れる／説明文が混ざるコードブロックの中身だけを貼る．途中で切れたら「続きを出して」と促す，または再依頼．プロンプトには「1ブロックだけ・省略せず全文出力」の指示が入っています．
コードを貼るときの注意 生成AI の返答全体ではなく，コードブロック（```javascript ... ```）の中身だけをコピーしてください．コードブロック右上の「コピー」ボタンを使うと自動的に中身だけになります．

  • ステンドグラス：ボロノイ図（Voronoi diagram）にもとづく平面分割。
  • 顔・数式アート・音の進化：IEC の一般的な応用例で、特定の原典はありません。
