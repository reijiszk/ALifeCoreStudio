v1.0IEC Studio 利用方法マニュアル

ブラウザで動く対話型進化計算（IEC）ツール

1IEC Studio とは

IEC Studio は，ブラウザだけで動く対話型進化計算（IEC：Interactive Evolutionary Computation）ツールです。インストール不要，ファイルをダブルクリックするだけで起動します。

通常の進化計算（GA）は「評価関数」で自動的に良し悪しを決めますが，IEC では人間の好みそのものが選択圧になります。画面の 3×3＝9 個体から「いいな」と思うものを選ぶと，それを親に次世代 9 個体が作られます。これをくり返すだけで，数式では測りにくい「美しさ・面白さ」に向かって形が進化します（リチャード・ドーキンスの「バイオモルフ」が古典例）。

このツールのねらい（考え方） 近年の生成AIの進展は，複雑系や人工生命の「作って理解する（構成論的）」モデリングを大きく変えつつあります。プロンプトで骨子を与えれば，完全な仕様でなくても様々なモデルを自動生成でき，必要に応じて AI に説明させて理解したり，対話しながらアイデアを洗練したりできます。一方で，全体を AI に任せると出来上がるものがばらばらになりがちです。
ALifeCoreStudio（ABM・EVO・IEC の3スタジオ）は，モデル構築・可視化・分析の共通の枠組みを固定したうえで，モデルの本質的な部分だけを生成AIで生み出せるようにした環境です。これにより，プログラミング未経験の初心者が発想を自由に形にする／学生が AI と協働してモデルを育てる／研究者が素早くプロトタイプを作る，といった利用が想定されています。枠組みの中で可能なモデルを自由に生み出すことを通じて，構成論的アプローチによる科学的理解を加速し，「どんな世界がありうるか」を思い描いて動かす楽しさを広げること——それがこのツールのねらいです。
EVO Studio との違い EVO Studio は評価関数で自動的に最良を選びます。IEC Studio はあなた自身がクリックで選ぶのがちがい。正解がなく好みで決まる題材（デザイン・形・模様）に向いています。

できること：9 個体を見比べて選び進化させる／1 親（変異のみ）と 2 親（交叉＋変異）を切り替える／変異率・変異幅をスライダーで調整する／遺伝子の定義と中央個体の中身を確認する／気に入った個体の遺伝子をコピー・保存・再現する／アニメーションする個体を動かす／作ったモデルを .js に保存・再読み込みする，など。

できないこと：インターネットアクセス，外部データ読み込み，3D 描画などはサポートしていません。

4進化の操作

個体を選ぶ

9 個体の中から好みのものをクリックします。すると、その個体を親に少しずつ変化させた次世代 9 個体が生まれます。中央のセル（★）は親そのままなので、選んだ形が必ず1つは残ります。

1親モードと2親モード

モード内容
1親 ─ 変異のみ（既定）気に入った個体を 1 つクリック。それを親に変異させた 9 個体が生まれる。1 方向にじっくり育てたいときに。
2親 ─ 交叉＋変異親 A・親 B の 2 つを順にクリック。両者の遺伝子を交叉（混合）した子が生まれる。2 つの良さを掛け合わせたいときに。

交叉方式

2 親モードでは、左下の 交叉方式 で 一様交叉／一点交叉／二点交叉を選べます。一様は遺伝子ごとにランダムに親を選び、一点・二点は配列を切れ目で分けて受け継ぎます。

初期化

グリッド下の操作バーにある ⟳ 初期化 で、ランダムな初期 9 個体に戻ります。行き詰まったら新しい出発点から探索できます。

集団の録画

グリッド下の ⏺ 録画 ボタンで、9個体をまとめて1本の動画として記録できます。隅に世代数が焼き込まれます。アニメーションするモデル（群れ、仮想生物）は動きごと、静止画のモデルは世代が進むごとの変化が記録されるので、選択のセッションをそのまま1本の動画として見せられます。もう一度押すと録画が終わり、ファイルがダウンロードされます。

隣の形式メニューでは MP4 / WebM / 自動 を選べます。MP4 は H.264 で書き出すため、QuickTime Player・PowerPoint・Keynote でそのまま開けます。動画は現在のサムネイルサイズで記録されるので、解像度を上げたいときは録画前に サイズ:大 以上を選んでください。

アニメーション

アニメ対応モデル（群れ・仮想生物）では、右に アニメーション が表示され、再生／停止と速度（0.1×〜8×）を調整できます。動作中はヘッダーに ● アニメ が点灯します。

5パラメータと遺伝子

演算パラメータ

右の「演算パラメータ」で変異の強さを調整します（次に生成する世代から反映。各項目の ⓘ に説明）。

パラメータ意味
変異率 mutRate各遺伝子が変化する確率。大きいほど 9 個体が大きくばらつく。
変異幅 mutScale1 回の変化の大きさ（倍率）。小さいと親に近く、大きいと大胆に変わる。

モデルによっては独自パラメータを持ちます（例：枝分かれ図形は 変異遺伝子数 nMut・変異の大きさ stepSize）。

遺伝子（定義と中央個体）

いま使われている遺伝子の定義（数値配列の長さ・各遺伝子の範囲 GENE_RANGES）と、中央個体（★）の遺伝子そのものがチップで表示されます。仮想生物のように geneGrid を持つモデルでは、形態や位相が色つきのグリッドとして分かりやすく表示されます。

遺伝子エディタ

気に入った個体を保存・再現するための欄です。

1
セルの 📋 遺伝子 で取り込む各セルにマウスを乗せると出るボタン。押すとその個体の遺伝子（JSON の数値配列）がエディタに入り、同時にコピーされます。メモ帳などに貼って保存できます。
2
↓ 中央に配置 / ⊕ 全体に展開保存しておいた遺伝子をエディタに貼り、中央個体に置いたり、親として 9 個体に展開したりできます。前に気に入った形から再開できます。

6結果の保存・再現

IEC では「気に入った形」を残すことが大切です。次の 3 通りで保存・再現できます。

方法用途
遺伝子をコピー各セルの 📋 遺伝子 で個体の遺伝子をコピー。テキストとして保存し、後で「遺伝子エディタ」に貼って復元（§5）。
.js 保存／開くコードバーの 💾 .js保存 でモデル（コード）を保存、📂 開く で読み込み。自作モデルは必ず保存を。
仕様書コピー📋 仕様書コピー で仕様書＋現在のコードを 生成AI に渡し、改良を相談できます。
📦 データ一式DL（ZIP・v1.0）系統チェックの隣の 📦 データ一式DL で、初期化以降のデータ一式を ZIP に書き出します。あとからの分析・再現に。詳細は下記。

系統と枝分かれ

グリッド下の 系統を表示 をオンにすると、各世代で選ばれた親が左から右へ並びます。サムネイルをクリックすると、その祖先から育種を続けられます。

それまでの系統は消えません。薄く表示されたまま 過去 として残り、次に個体を選んだ時点で、クリックした祖先から新しい系統が 現在 として始まります。過去の系統の祖先もクリックできるので、どこからでも何度でも枝分かれできます。保持されるのは直近4本までで、それを超えると古いものから消えます。⟳ 初期化 ですべて消去されます。

ZIP 出力では、現在の系統が lineage.csv に、保持されている全系統が data.json の lineageBranches に記録されます。

📦 データ一式ダウンロード（ZIP・v1.0）

グリッド下、系統を表示 の隣の 📦 データ一式DL を押すと、初期化以降のデータ一式を 1 つの ZIP に書き出します。中身は次の通りです。

ファイル内容
metadata.jsonモデル名・書き出し日時・世代数・遺伝子長に加え、実験設定（settings）＝パラメータ・選択モード（変異のみ／交叉＋変異）・交叉方式・遺伝子の範囲・乱数シード（seed）。
model.jsこの実験を生成したモデルのコードそのもの。コード欄に貼り戻して ▶ 適用 すれば再現できます。
frames.jsonl各世代の全9個体の遺伝子（1 行 1 世代の JSON。{"tick":<世代>, "state":{"population":…, "chosen":…}}）。IEC は軽いので常に記録され、同梱ビュワーで各世代を再生できます。
lineage.csv各世代で選んだ親（中央 ★ 個体）の遺伝子履歴。列は step, gen, g0, g1, …。
population.csv現在の9個体の遺伝子。is_center=1 が中央（★）個体。
data.json設定・系統・現在の個体群の全データをまとめた構造化 JSON。プログラムからの読み込み向け。

各世代の再現とビュワー再生

あとから各世代の様子を再現できるよう、IEC では各世代の全9個体を frames.jsonl に常に記録します（1回のクリック＝1世代ぶんの軽いデータなので、記録のオン／オフは不要です）。あわせて変異・交叉の乱数を固定するシード（seed）も記録します。

書き出した ZIP を、リポジトリ直下の ALifeCoreStudio_Viewer.html にドロップすると、各世代の9個体を、そのモデル自身の描画コードでグリッド表示しながらタイムライン再生できます（選んだ個体には ★）。組み込みモデルだけでなく、改変・新規作成したモデルでも動きます。

7生成AI でコードを作る

✨ 新規作成プロンプト を押すと仕様書がコピーされます。生成AI に貼り、【実装する題材】を書いて送ると、貼り付けるだけのコードが返ります。

モデルの記述仕様（要点）

// 静止画モデル：必須の3関数
function createInitialGenome() { /* 数値の配列を返す（個体の遺伝子）*/ }
function mutateGenome(genome, params) { /* 変異させた新しい配列を返す */ }
function drawPhenotype(ctx, genome, W, H) { /* 遺伝子を絵にして描く */ }

// アニメーションモデル：ANIMATED=true と3関数（drawPhenotype の代わり）
const ANIMATED = true;
function initState(genome, W, H) { /* アニメ初期状態を返す */ }
function stepState(state, dt, genome, W, H) { /* 1フレーム進める */ }
function drawFrame(ctx, state, genome, W, H) { /* 現在の状態を描く */ }

// 任意
const GENE_RANGES = [ [min,max], ... ]; // 各遺伝子の範囲
const PARAM_DEFS = [ ... ];            // スライダー（help を付けると親切）
function geneGrid(genome) { ... }       // 遺伝子を色つきグリッドで表示
補足 静止画モデルの mutateGenome だけが params（スライダーの値）を受け取ります。drawPhenotype／initState 等は遺伝子と描画領域だけを受け取ります。アニメ速度スライダーは ANIMATED=true のとき自動表示され、dt（経過時間×速度）が stepState に渡されます。
伝え方のコツ 「何の形・模様を」「どんな遺伝子（変えられる要素）で」を明確に。遺伝子を少し変えると見た目が連続的に変わるようにしてもらうと、9 個体の見比べがうまくいきます。動かしたいときは「アニメーションで」と添えてください。

1
コードをコピー生成AI のコードブロック右上「コピー」で、中身だけをコピーします。
2
コード欄に貼る▸ コード を開き、Ctrl+A（Mac: ⌘+A）で全選択してから貼り付け。
3

9コードを改変する

✏️ 改変プロンプト を押すと、現在のコードと改変指示の枠がコピーされます。生成AI に貼り、変えたいことを箇条書きすれば、改変後のコード全体が返ります。コード欄を全選択して入れ替え、▶ 適用。

📖 説明プロンプト を押すと、いま動かしているコードがどんな題材かを説明させるプロンプト（概要・アルゴリズムの説明・疑似コードを求める内容）がコピーされます。生成AI に貼ると、実装に忠実な解説が得られます。また生成・改変したコードに const TITLE = 'モデル名' を入れておくと、ブラウザのタブ名・「このモデルの説明」の見出し・💾 .js保存 のファイル名（例 枝分かれ図形.js）に反映されます。

無料版でも失敗しにくくする工夫 プロンプトは最小限の仕様にしぼり、冒頭と末尾で「コードブロックを1つだけ・省略せず全文出力」を強く指示しています（無料版・小型モデルでの出力切れや説明文混入を減らすため）。✏️ 改変プロンプト では 【改変したい内容】を末尾に置いているので、そこに変更点を箇条書きします。
改変のコツ 一度に大きく変えず、小さな変更を 1〜2 個ずつ。気に入った状態は 💾 .js保存 や遺伝子のコピーで残しておくと安全です。

🤖 AI生成 ─ 生成AI の API に直接つなぐ（LM Studio / クラウド）

コードバーの 🤖 AI生成 を押すと、OpenAI 互換 API に直接つないで改変・新規作成ができます。返ってきたコードは自動でコード欄に挿入されます（実行は ▶ 適用 を押すまで行われません）。コピー＆ペーストは不要です。

  • ローカル（LM Studio など）：ローカルサーバを起動し、サーバ設定で「Enable CORS」を ON。エンドポイントは http://localhost:1234（API キー不要）。
  • クラウド（OpenAI 互換）：例 ─ OpenRouter https://openrouter.ai/api/v1、DeepInfra https://api.deepinfra.com/v1/openai、OpenAI https://api.openai.com/v1。API キーが必要（多くは従量課金）。
  • モデル名は 🔄 一覧取得 で選べます（手入力も可）。設定はブラウザに記憶されます。
うまく繋がらないとき 「Failed to fetch」はサーバ未起動・CORS 未設定・URL 違いが主な原因です。ブラウザで http://localhost:1234/v1/models を直接開いて JSON が出るか確認してください。クラウドはサービス側が CORS に対応している必要があります（OpenRouter・DeepInfra は対応）。

枝分かれ図形（ドーキンス9遺伝子）

リチャード・ドーキンス『盲目の時計職人』の「バイオモルフ」を再現したモデルです。遺伝子は 9 個の整数。最初の 8 個が枝の方向・長さを、9 個目が枝分かれの深さを決めます。中心から左右対称に再帰的に枝を伸ばし、白黒で描きます。

変異の特徴：原典どおり「いくつかの遺伝子を ±1 ずつ変える」ように設計され、変異遺伝子数 nMut・変異の大きさ stepSize で調整できます（既定は 2／1 ＝ 2つの遺伝子が1段階ずつ動く）。世代を重ねると、木が虫・鳥・植物のような形へ次々と変わっていきます。

顔の進化

目・眉・鼻・口・輪郭・髪などのパーツの形や配置を遺伝子に持ち、好みの顔つきへ進化させます。「かわいい」「こわい」など言葉にしにくい基準で選べるのが IEC らしいモデルです。眉や口角の角度を変えると表情が変わります。

ステンドグラス

平面に置いた複数の種点からボロノイ図（各点に最も近い領域への分割）を作り、各領域に色を塗ります。遺伝子は種点の位置と色。空間分割がそのまま模様になり、種点が動くとガラスの割り付けが変化します。

数式アート

2 変数関数 z = f(x, y)（sin の重ね合わせなど）の値を色にマッピングして模様を描きます。遺伝子は式の係数。係数が少し変わると模様が連続的に変化するので、IEC で「好きな模様」を探すのに向いています。

群れ（フロッキング）

Reynolds の Boids（分離・整列・凝集の 3 ルール）で動く群れのアニメーションです。遺伝子は 3 ルールの強さや知覚半径・速度など。動きの個性（まとまり方・散らばり方）を見比べて選び、好みの群れ挙動へ進化させます。右の アニメーション で再生・速度を調整します。

仮想生物（ソフトボディ・ボクセル）

5×5 のボクセル（空・剛体・軟体・水平／垂直アクチュエータ）で体を作り、アクチュエータの周期的な伸縮で動くソフトボディ生物です。遺伝子は形態（各マスの種類）と制御（位相）。geneGrid により、形態と位相が色つきの 5×5 グリッドとして表示されます。動きや体つきの面白さで選んで進化させます（アニメーション）。

音の進化

8 音の短いメロディを遺伝子に持ち、各セルの ▶ 鳴らす で実際に聴いてから選べるモデルです。目で見る形ではなく耳で選ぶ IEC の例で、心地よい・面白いと感じたメロディをクリックして進化させます。

10エラーと対処法

▶ 適用 時にエラーが起きると、コードバーに赤いメッセージが出ます。原因の行番号・その行の内容・ヒントが日本語で表示されます。使えない構文（class・document.*・window.*・fetch・setTimeout・import など）は適用前に検出されます。

11よくある質問

Q. 9 個体が似すぎていて選べません。
A. 右の 変異率・変異幅 を上げると、もっとばらつきます。逆に変わりすぎるなら下げてください。

Q. 変わりすぎて方向が定まりません。
A. 変異率・変異幅 を下げると、親に近い穏やかな変化になります。1 親モードでじっくり育てるのも有効です。

Q. 気に入った形に戻したいです。
A. 気に入った個体は 📋 遺伝子 でコピーして保存。あとで「遺伝子エディタ」に貼って ↓ 中央に配置 で復元できます（§5）。

Q. スライダーが出ません。
A. PARAM_DEFS が無い場合は、既定の 変異率・変異幅 の 2 つだけ表示されます。独自スライダーが欲しいときは 生成AI に「PARAM_DEFS を追加して。help も付けて」と依頼してください。

Q. アニメーションが動きません。
A. アニメには const ANIMATED = true と initState／stepState／drawFrame が必要です。静止画モデルには アニメーション パネルは出ません。

Q. 2 親モードで子ができません。
A. 2 親モードでは 2 個体を順にクリックする必要があります。1 つだけだと選択待ちのままです。交叉方式は左下で選べます。

Q. ブラウザを閉じるとコードが消えます。
A. 自動保存はしません。💾 .js保存 でファイルに残し、次回 📂 開く で読み込んでください。気に入った個体の遺伝子もコピーして保存しておくと安心です。
