ABM Studio v1.0: How to Use

✕ Close

ABM Studio is a tool for writing agent-based models with three functions (setup, step, and draw) and observing behavior and graphs while changing parameters in real time. It also supports smartphone and tablet screen widths.

Basic Operation

  • ▶ Run / ⏸ Pause: start/stop the model. ⏭ 1 tick advances a single step.
  • ⟳ Initialize: rebuilds the initial state using the current parameters.
  • Run Speed: steps per frame (t/f). Adjustable logarithmically from about 0.1 to 60: setting it below 1 advances only once every few frames, letting you observe slowly. Draw Skip: draws only once every N frames to speed up computation (useful when there are many agents).
  • Max Tick: turning the toggle ON lets you choose the behavior when the specified tick is reached (the On Reach selector that appears to the right, default ⏹ Stop only). ⏹ Stop only = pauses in place without reinitializing (does not return to the start). Switching to 🔁 Loop automatically reinitializes and repeats from the start. If the toggle is OFF, max tick is ignored.

How Parameter Changes Are Applied

  • Apply Immediately (default): moving a slider is reflected instantly in the running model via step. Existing history (graphs) is not cleared.
  • Auto-Reinitialize: moving a slider automatically reinitializes the model.
  • Values used only for initial placement (density, initial population, etc.) have no effect via step, so changing them shows an "Initialization needed" hint. Press Initialize Now or ⟳ Initialize to apply it. History is never cleared automatically.

Saving and Comparing Experiments

  • 📸 Save Snapshot: saves the current graph (run results) and full parameter set, letting you compare them overlaid as a light line on the graph. Useful for switching between conditions A / B in a presentation.
  • Each experiment can be shown/hidden with 👁 and deleted with ✕. ⬇ Save CSV exports all graphs plus saved experiments together as a CSV file.
  • Each graph's ⬇ CSV (clipboard), 💾 (file), and 🖼 Image are also available.

Manual Range Settings for Graph Axes

  • Pressing ⚙ Axes in the top-right of each graph opens range-setting fields for the vertical (Y) and horizontal (X, tick) axes.
  • Auto-scale (default): as before, automatically adjusts the axes to fit the range of the data.
  • Manual: fix the range by specifying numeric min/max values. Use this when you want to zoom into a specific range or align the appearance of multiple graphs.

Things to Watch For When Writing Code (Avoiding Errors)

Code is evaluated with new Function(). The following syntax cannot be used. Using it causes an error when applying, showing the offending line number and a hint below the code field.

  • The class keyword → use an object literal {} instead
  • DOM manipulation such as document.* / window.*, and addEventListener
  • fetch / XMLHttpRequest (external communication)
  • setTimeout / setInterval (asynchronous processing)
  • import / export statements

When asking ChatGPT for a modification, copying and using the ✏️ Modify Prompt / ✨ New Model Prompt in the code bar lets you make the request with the specification, prohibitions, and the instruction to "add a brief explanatory comment" already included.

🐍 Python Prompt: copies a prompt that converts the current code into a standalone Python script (using matplotlib) plus a requirements.txt. Pasting it into a generative AI returns two code blocks (the Python script and requirements.txt).

💾 HTML Export: exports a standalone HTML file (no code-editing / AI-generation UI) that runs only the currently running model as-is. Handy for distribution or as course handouts.

🔊 Sound: use the 🔊 button in the header to toggle sound on/off. If the model calls Sound.beep(...) or Sound.note(...), sound plays (enabled after the first click). The trick is not to overuse it: play sound only on specific events.

Saving and Loading

  • 💾 Save .js: saves the current code as a .js file. 📂 Open: loads a saved .js / .txt file.
  • ⏺ Record: saves the canvas as a video. Choose MP4 / WebM / Auto from the menu next to it (formats unsupported by the environment automatically fall back to WebM).

What Parameters Mean (ⓘ)

When a ⓘ appears next to a parameter name, hovering over it shows an explanation. Adding help: 'explanation text' to PARAM_DEFS in the code makes that explanation appear.
